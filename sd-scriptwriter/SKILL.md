# 场景剧本创作

根据素材、篇幅与改编要求创作或修改中文场景剧本。选题与故事重构见[sd-story-development](../sd-story-development/SKILL.md)。

## 写作流程

1. 明确故事主线、人物关系、核心回报与保留设定。
2. 建立角色、物理场景、关键道具与时间线档案。
3. 按“目标 — 阻力 — 选择 — 结果”规划分场大纲。
4. 用动作、对白和声音编写场景正文，完成后按[交稿自检](references/quality-gates.md)核对。

具体动作、对白与转场写法见[剧本执行方法](references/execution-rules.md)。

## 交付内容

按用户请求的实际范围交付（单场、单集、分集大纲或完整文学开发包）。完整文学开发包可包含：
1. 项目全局设定
2. 剧本总纲与系列规划
3. 核心梗与一句话卖点
4. 故事梗概
5. 人物小传
6. 分场/分集大纲
7. 视听元素总览
8. 场景剧本正文（独立文件建议命名为`片名_场景剧本.md`）

### 标准单场格式

~~~text
01-01  昏  阴  外  旧院门

出场人物：晚晴
道具：铜钥匙

△ 晚晴停在石阶上，面向入口右侧门扇，目光从门闩移向新锁。她抬手，用指尖轻碰锁环后停住。
【音效：指尖碰到锁环，铜件轻响。】
晚晴（压低声音）：门锁换过了。
△ 她收回手，沿门框缝隙查看。
~~~

场次连续编号，动作以`△`开头，音效以`【音效：……】`标注，台词写明说话者（OS/旁白在括号中注明）。进入分镜制作时按[制作流程](../references/production-workflow.md)登记源剧本基线与定位映射。
