# 剧本执行方法

将大纲转化为可阅读、可表演、可交接分镜的自然语言场景正文。

## 1. 行动、空间与情绪

- **建立空间与朝向**：场次开头交代角色所在位置、朝向与关键定锚物（门、窗、台阶、桌案等）。
- **完整动作链**：重要操作写出“准备 → 路径 → 接触 → 结果”，不跳过中间过程；角色察觉异常时交代视线落点或声源方向，道具移位或状态改变后在后续动作中持续承接。
- **可见反应**：用具体肢体与接触动作外化情绪（如“把钥匙握进掌心，指节收紧”），也可用静止、沉默和空景传递信息，不为每句台词机械附加小动作。

## 2. 场次划分与转场

- 按时空变化或叙事任务切换划分场次，每场明确人物目标、阻力与场尾局面变化。
- 转场利用动作承接、视线目标、关键道具、声音先入或时间提示连接；闪回或跳时须交代清楚回到主线的时空锚点。
- 正文使用自然语言描述可见变化，焦距、光圈与生成参数留给分镜与提示词环节。

## 3. 台词与声音

- **角色台词**：按身份、处境与目标区分词句长短和停顿；关键句标注简要语气，标点配合自然断句。
- **OS与旁白**：内心独白标明所属角色（如`晚晴（OS）：`），叙述性旁白标明`旁白：`或`NAR：`，避免与画面已知信息简单重复。
- **音效与音乐**：在关键接触或异常线索处写明声源、触发动作与质感；音乐提示情绪方向与进出节点。
- **画面文字**：信件、招牌、屏幕或字幕卡写明准确原文、载体位置与叙事用途。
