# 剧本设定与交稿自检

用于组织剧本前期设定并在交付前自检。正式审阅报告见[剧本证据审阅](../../sd-story-development/references/script-review.md)。

## 1. 设定要素

仅为当前故事实际使用的人物、地点与物件建立档案：

| 类别 | 设定要点 |
|---|---|
| 角色 | 名称、年龄感、体型比例、不可变面部五官骨相、发型、服饰层次与固有配色、鞋履配饰、声线与语言习惯 |
| 场景 | 建筑围合、出入口、主要陈设与定锚物、材质、基础空间特征 |
| 道具 | 器型轮廓、尺寸、材质、固有纹样或磨损特征、操作与握持方式 |
| 系列 | 人物关系、时间线、跨集状态变化、未回收伏笔与下集入口 |

## 2. 交稿前自检清单

| 检查项 | 核对内容 |
|---|---|
| 范围与保留项 | 交付体裁（梗概/大纲/单场/全剧）及用户指定的保留设定是否完整落地 |
| 单场推进 | 每场是否产生信息、关系或处境变化；人物位置、视线、道具交接与动作结果是否连贯 |
| 台词与声音 | 人物口吻是否有区分度；台词朗读是否自然；OS、旁白、音效与配乐是否承担实际叙事功能 |
| 前后衔接 | 跨场时空与物品状态是否一致；关键转折是否有前置铺垫 |
| 文本清理 | 移除未填占位符、重复设定与自检过程说明 |
