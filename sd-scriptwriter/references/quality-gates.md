# 剧本设定与交稿自检

编剧用于组织设定并核对本次交付。逐项登记问题、出具审阅结论时使用 [证据审阅](../../sd-story-development/references/script-review.md)。

## 设定记录

按当前故事与交付范围建立需要的设定，不为未使用的人物或物件扩充档案。

| 对象 | 建议记录 |
|---|---|
| 角色 | 名称、年龄感、体型、五官与发型、服饰鞋履、辨识细节、动作习惯、声线与语言习惯 |
| 场景 | 出入口、墙体与纵深、主要陈设与定锚物、材质、环境变化；基础空间与叙事光影分开 |
| 道具 | 外形、材质、纹理与损耗、操作位置、功能、与角色的接触方式 |
| 系列 | 人物关系、时间线、资产变化、未回收线索、下一集衔接 |

原素材、参考图或声音影响了哪个角色、场景、情节，应能查到来源；区分直接采用的内容与仅参考的表达方向。历史、职业、文化或品牌事实未核实时标明。

## 按载体选择节奏

- 短剧、漫剧：检查开篇问题、信息变化、局部回报及段尾入口。
- 长剧、电影：检查主线、支线与人物弧光的配合，留白有叙事作用。
- 广告、电商：检查受众问题、产品信息与行动目标，品牌事实有来源。
- MV：依据实际音乐结构与歌词安排段落，精确卡点交给音频与后期实测。
- 纪实、文化题材：分清事实、创作补充与待核验内容。

篇幅、场次数量与停顿由实际内容决定。

## 交稿前核对

| 范围 | 核对内容 |
|---|---|
| 本次请求 | 交付的梗概、大纲、人物、完整剧本或单场是否符合请求，保留项是否落地 |
| 单场 | 是否发生信息、关系或局面变化；人物行为有动机；位置、视线、道具与动作结果可追踪 |
| 台词与声音 | 朗读是否自然且区分人物；停顿与动作有时间，估算或实测依据明确；OS、旁白、音效与音乐是否承担必要作用 |
| 前后连接 | 转场可理解；关键转折有准备；人物、物件和时间状态衔接 |
| 全文或系列 | 本范围承诺的回报是否兑现；人物变化有依据；线索回收及后续入口可查 |
| 交付清理 | 删除占位符和重复设定，标明未决事实；正文不夹带自检过程 |

只请求大纲、剧本或单场时直接交付相应内容；定稿与后续制作按 [制作流程](../../references/production-workflow.md) 衔接。
