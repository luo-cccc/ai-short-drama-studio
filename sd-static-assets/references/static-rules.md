# 静态资产设计方法

模板结构见[templates.md](templates.md)，公共规则见[rule-authority.md](../../references/rule-authority.md)。

## 1. 角色与道具一致性

1. **不可变骨相DNA与可变服装分离**：
   - `characters[].description`须包含**至少2项不可变面部骨相特征**（脸型与下颌折角、眉形、眼型、瞳色、鼻唇、泪痣/疤痕等唯一标识）与**默认服装状态**。
   - `T1`左区55%全身三视图头部与右区45%四格面部特写必须共享同一张脸与头颈肩关系。
   - 泪痣、单侧疤痕、斜刘海等不对称特征在设定中标明**解剖左右**，在分镜中换算为当前相机视角下的**画面左右**。
2. **角色换装／战损／湿身变体（锁脸换衣）**：
   - 同一角色换装或状态变化时沿用原`CHAR-` ID，新增变体静态`PROMPT-`。
   - 变体`T1`优先将`slice_grid.py --mode t1`切出的正面头像`char_head_01_front.png`绑为`@图片1`，仅锁死五官骨相，明确`禁止继承原图的服装款式、服装固有配色、旧发型或旧状态`（正向参考中删去“服装结构与固有配色”）。
3. **道具跨状态变体**：
   - 同一道具（`PROP-`）发生开合、拆解、破损、染血或点亮变化时，变体`T2`用`@图片1`绑定首发`T2`母图锁死器型尺寸、材质与纹样，声明`禁止继承原图的闭合或完好旧状态`。

## 2. 空间拓扑与正反打对位

1. **场景跨时段／跨天气／跨破坏状态变体**：
   - 变体`T3`、扩图`T4`或多视角`T5`通过`@图片1`绑定基准场景母图，锁死建筑围合、门窗开口与定锚物几何位置，排除旧时段光照、色温与旧状态。
   - 彩色故事板`T6`与单帧重绘`T6C`有戏剧性叙事光影时，场景参考仅继承空间结构与固有材质，不继承`T3`基础漫射光。
2. **四向空间与T5切片绑定**：
   - 明确空间的主轴朝向、左右翼与定锚物（统一使用建筑相对方位，禁用罗盘东南西北）。
   - `T5`生成后用`slice_grid.py --mode grid --grid-kind spatial`切分为`Shot_01.png`–`Shot_09.png`，按分镜相机真实位置与朝向选择对应视角切片，反打镜头按反向真实可见范围重写背景。

## 3. 镜头参数与风格层次

| 景别类型 | 推荐光圈 | 视觉重点 |
|---|---|---|
| 全景／空间参考（T3/T4/T5） | `f/8–f/16` | 建筑围合、空间纵深与定锚物清晰 |
| 中景／双人关系 | `f/4–f/5.6` | 人物姿态关系与背景空间可读 |
| 近景／道具特写（T2） | `f/1.4–f/2.8` | 焦点聚于核心细节，背景适度虚化 |

- **场景概念图起始机位参考**：小型封闭室内（`24mm, f/8, 平视`）、露天院落（`24mm, f/8, 微俯`）、半开放商铺（`24mm, f/8, 轻微俯视`）、中大型室内（`24mm, f/8, 平视`）、开阔户外（`35mm, f/11, 高位斜俯`）。
- 角色与道具固有配色写在主体层，皮肤质感、渲染媒介与叙事光影写在风格层；`T6B`仅保留黑白灰与线形结构。

## 4. 物理切图与首尾帧衔接

使用`scripts/slice_grid.py`切分已生成的图板（详见[本地工具](../../references/tools.md#4-图像切分scriptsslice_gridpy)）：
- **防二手切片换脸**：`T6`/`T6B`切出的1/9单格像素较低（且`T6B`为线稿），投喂给`T6C`或`T8`/`T9`时，`@图片1`/`@素材N`必须声明**只取构图、站位与身体姿态，禁止继承人物五官面容与服饰细节**；角色真脸由绑定的零代`T1`或`char_head_01_front.png`提供。
- **同镜首尾帧互锁**：同一分镜分别制作起始首帧（`Shot_01`）与切出尾帧（`Shot_09`）两张`T6C`时，生成尾帧`T6C`建议增绑已验收的本镜首帧`T6C`，锁定人脸、光影色温与背景微观质感。

## 5. 防连续参考代际噪点与伪影累积

连续使用同一参考图或将衍生图串行垫图时，VAE重编码与高频边缘强化会导致颗粒、白边与脏斑指数级放大。须执行以下四项防噪规范：

1. **零代母图（Gen-0）星型直连，严禁串行传话筒叠代**：
   - 将首发验收的`T1`（及切出的`char_head_01_front.png`）、`T2`、`T3`定为唯一**零代母图（Gen-0）**，入库前可做一次轻度无损降噪。
   - 后续所有换装/战损变体`T1`、跨状态`T2`/`T3`、扩图`T4`、多视角`T5`与单帧重绘`T6C`，必须**直接回绑零代母图**，严禁拿变体图再生下一代变体图（`Gen-0 -> 变体1 -> 变体2`会触发QC `WARN`）。
2. **用`slice_grid.py --mode t1`高占比头像切片替代`T1`整图重复投喂**：
   - `T1`整图中单张脸像素占比小，反复整图投喂会迫使模型拉高局部高频对比度产生面部麻点；锁脸应优先投喂切出的高分辨率`char_head_01_front.png`。
3. **结构桥接与色彩渲染解耦（优先`T6B`线稿接`T6C`）**：
   - 分镜九宫格优先采用`T6B`（黑白线稿）定构图与姿态，避免在1/9分辨率的彩色`T6`切片上叠加二次彩色重绘；`T6C`通过`@图片1`仅取`T6B`切片构图，色彩与皮肤质感由零代母图一次性干净渲染。
4. **衍生图提示词禁用高频颗粒词并写入纯净平滑描述**：
   - 在带`@图片N`参考的静态提示词（变体`T1/T2/T3`、`T4/T5`、`T6C`）中，**禁用`胶片颗粒`、`颗粒感`、`粗粝颗粒`、`微距毛孔`、`极致锐化`、`高频细节`等词汇**（否则触发QC `WARN`），防止与参考图纹理双重锐化；在风格层与尾约束改用“画面干净通透，明暗过渡平滑柔和，皮肤与材质表面细腻干净”。
   - 全程使用无损PNG传递，生图端参考权重建议控制在`0.60–0.75`。
