# 静态资产设计方法

模板字段与版式见[静态模板](templates.md)，层序、参数、画幅、参考继承和尾约束以[规则权威表](../../references/rule-authority.md)为准。全流程沿用[制作交接](../../references/production-workflow.md)中的设定与资产 ID，数据与 QC 见[项目数据契约](../../references/project-data.md)。

## 角色与道具

同一角色形态、道具和场景使用稳定身份。人物描述以名称起始，保持脸型、发型、体型、服饰、鞋履与配饰一致；背面或侧面可见时补齐对应结构。局部特写只承载该视角需要的信息。

T1 角色板的脸部、正侧背三视图与细节面板展示同一形态。三视图完整到足，各区五官、服饰和配饰对应；细节可选鞋履、面料、服装构造和标志性配饰。非人类角色换成足爪、皮毛或鳞甲、躯干与辨识特征，保留同样的造型对应关系。

T2 聚焦一件可分离道具的单视角特写，说明形状、构造、材质、纹样和辨识细节。

T1/T2 使用纯白背景与均匀柔光，减弱戏剧性阴影及环境色，便于后续参考。背景放在场景层，照明放在风格层；物体仍保留可读的体积明暗。

## 空间与参考图

T3/T5 用基础可读光记录场所结构与材质，叙事光影留给镜头设计。T5、彩色 T6 与线稿 T6B 的继承范围分别按 R-REF-001 处理。

为出场角色分别绑定可识别的参考资产；空间复杂时结合概念图和多视角图，缺图时注明待生成项。素材位逐条声明继承与排除范围，并按实际平台能力分配。

### 九视角空间完整性

先确定建筑围合、出入口、门窗、家具和定锚物的相对位置，再选择机位。各视角共享同一拓扑，逐格描述实际可见的边界、遮挡与物件位置，避免复制物品清单充当不同视角。封闭室内应保留墙体与屋顶关系，不能因机位选择变成剖面、沙盘或开放院落。

空间描述分三步：

1. 物理空间：以入口墙、正对面墙、入口两侧墙及固定物件定义位置关系。
2. 相机位置：说明所在物理位置与拍摄朝向。
3. 画面布局：由前两项推导可见位置与遮挡。

T5 多机位统一使用建筑相对方位，不写罗盘方向。单视角可用画面方位或建筑方位，同一提示词保持一套参照。

### 场景扩图

区分已知结构与待补区域：已有门窗、陈设、连接关系、材质和配色保持不变，镜头外区域按已有结构延伸。新机位可以改变焦点，不能借此重新设计原场景。已知信息与推定区域写在设计说明中，返图后检查衔接。

T4/T5/T6/6B 正文清楚描述当前主体、空间与视角，参考行说明继承范围；多视角按可见内容分别写，不逐格重述完整场景档案。

## 镜头与风格

静态画面按需要选择镜头类型、焦距、光圈、透视、景别、机位、构图、景深与焦点，并配合观看效果描述。故事板呈现定格状态，运镜轨迹留在调度图与动态设计中。

| 景别用途 | 光圈参考 | 关注点 |
|---|---|---|
| 大空间与空间参考 | f/8–f/16 | 建筑边界、近远关系与陈设清晰 |
| 中景 | f/4–f/5.6 | 主体关系与背景可读性 |
| 近景与细节 | f/1.4–f/2.8 | 焦点与前后层次，不裁掉关键结构 |

### 场景概念图机位参考

| 空间类型 | 起始参数 | 选择理由 |
|---|---|---|
| 小型封闭室内 | 24mm、f/8、平视 | 保留完整围合与室内尺度感 |
| 露天院落 | 24mm、f/8、微俯至斜俯 | 看清入口与建筑围合 |
| 半开放商铺 | 24mm、f/8、轻微俯视 | 兼顾入口、台面与内部纵深 |
| 中大型室内 | 24mm、f/8、平视 | 表现空间轴线与结构层次 |
| 开阔户外 | 35mm、f/11、高位斜俯 | 展示地形与远端关系 |

以上参数是设计起点，按空间尺度和风格调整。T5 俯视与远景需考虑屋顶遮挡；室内无法成立的垂直俯视改为室内斜俯。扩展机位可选 85mm 细节、35mm 走廊纵深或 50mm 侧面平视，并补充实际可见内容。

### 材质与配色

先确定表现方法，再选择材质、光线色彩、构图和镜头。角色固有造型与配色放在主体层，皮肤及渲染质感放在风格层；空间结构放在场景层，照明放在风格层。同一项目使用一致的风格、颜色名称与已有色号。T6B 只保留结构与灰阶。

| 项目风格 | 材质与人物表现示例 | 光影与质感示例 |
|---|---|---|
| 写实或写实 3D | 自然肤色、皮肤纹理、物理材质 | 柔和高光、细腻纹理或胶片颗粒 |
| 3D 动漫 | 简化人物造型、动漫材质 | 清晰体积、可控高光与色彩层次 |
| 2D 动漫 | 平涂色块、明确轮廓 | 赛璐珞分层、纯净色面 |
| 卡通 | 夸张比例、简化材质 | 大色块与明确明暗分区 |
| CG 或混合风格 | 依项目选择材质 | 统一渲染和光照逻辑 |

风格措辞按项目取用，避免重复前缀、无关相机品牌或不适合平涂与卡通的写实术语。

## 故事板

T6/T6B 九格是剧情关键帧，不等于九个物理镜头。每格标明所属物理镜头，第一格对应分镜开头，第九格对应结束。相邻格保持角色方位、视线、动作结果与环境痕迹，位置改变有前后依据。

分区比例、信息栏和格下标注按[模板](templates.md#模板6彩色影视故事板)填写。剧情画面不叠加调度线、参数或台词，相关信息留在左栏或文字交付。

调度图包含场景边界、定锚物、角色起止位置与朝向、机位编号和轨迹图例。轨迹只在调度图示意，剧情格呈现静态瞬间。按需使用特效区，展示特效本身的结构或材质细节。

## 交付与返图

交付前核对模板字段、构图、视觉焦点、配色光影、姿态、角色特征和空间关系，再按[项目数据契约](../../references/project-data.md)检查实际提示词。

返图逐张比对造型与空间，核对外画幅、格内画幅及信息区可读性；T6B 额外检查黑白灰表现，以及彩色参考的渲染、光色或标注是否渗入剧情画面。
