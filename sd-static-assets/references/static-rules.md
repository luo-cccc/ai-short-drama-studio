# 静态资产设计方法

本文保留静态设计方法。层序、参数、画幅、参考继承、字数和尾约束以[公共规则](../../references/rule-authority.md)为准；实际字段见[模板库](templates.md)。下列规则编号保留为其他模块的引用标识，不表示优先级。所有视觉效果均需返图核对，文字检查不能证明生成结果一致。

## 角色与道具

**规则26/30/31/35/86：资产复用与可见特征。** 每个角色形态、道具和场景建立稳定身份。人物描述以名称起始，保持脸型、发型、体型、服饰、鞋履与配饰一致；背面或侧面可见时补齐对应特征。局部特写只承载该视角需要的信息，不用不可见细节淹没焦点。

**规则75/76/77：标准资产光照。** T1/T2 使用纯白背景和均匀柔光，减弱戏剧性阴影与环境色，便于后续参考。背景只在③描述，光照只在⑤描述。纯白背景、均匀照明是设计目标，不声称物体没有任何明暗。

**规则88/89：角色板。** T1 为同一角色的脸部、三视图与细节分解：左区35%脸部特写，中区45%完整正面/侧面/背面，右区20%细节。细节通常为鞋履、面料、服装构造和标志性配饰；非人类角色替换为足爪、皮毛/鳞甲、躯干与辨识特征。三视图完整到足，各区域的五官、服饰和配饰应逐一对应。

**规则90：道具微距。** T2 为一件可分离道具的单视角特写，说明形状、构造、材质、纹样和辨识细节，不混入三视图或角色设定板指令。

## 空间与参考图

**规则7/82/98：基础光与参考继承。** T3/T5 只记录基础可读光下的场所结构与材质，叙事光影按公共 R-LIGHT-001 分离。T5 与彩色 T6 的参考继承、T6B 的结构继承分别按 R-REF-001，不使用一条“场景图禁止继承光影”覆盖所有模式。

**规则32/33/34/84：参考计划。** 为出场角色分别绑定参考资产；空间复杂时同时使用概念图和多视角图，缺图时明确待生成项。素材位逐条声明继承和排除范围，数量按实际平台能力选择。故事板调度图记录角色轴线和机位；JSON 素材位绑定只证明逻辑引用存在，不证明图片已经生成。

**规则94：九视角空间完整性。** 先确定建筑围合、出入口、门窗、家具和定锚物的相对位置，再选择机位。各视角共享同一拓扑，逐格描述该机位实际可见的建筑边界、遮挡与物件位置，不能复制一份物品清单充当九个不同视角。封闭室内应保持墙体与屋顶关系，不意外画成剖面、沙盘或开放院落。

**规则100：空间方位三层框架。**

1. 物理空间：以入口墙、正对面墙、入口两侧墙及固定物件定义位置关系。
2. 相机位置：说明相机所在物理位置及拍摄朝向。
3. 画面布局：由前两项推导可见位置与遮挡，不用独立的画面左右反过来改写物理布局。

T5 的多个机位统一使用建筑相对方位。单视角可使用画面相对方位或建筑相对方位，但同一提示词保持一套体系；不写罗盘方向。

**规则103：场景扩图。** 区分已知结构与待补区域：已有门窗、陈设、连接关系、材质和配色保持不变；镜头外区域按已有空间结构合理延伸。主体焦点可改变，不能以“新机位”为由重新设计原场景。已知信息与推定区域在设计说明中注明，返图后检查衔接。

**规则104：参考与文字的分工。** T4/T5/T6 的正文仍要清楚描述主体、空间和当前视角。参考行负责继承范围，正文负责当前画面；不使用“同上”“参考图已承载故省略”。多视角正文按可见内容分别写，不在每格重复整个场景档案。

## 镜头与风格

**规则18/91：静态镜头设计。** 根据画面需要记录镜头类型、焦距、光圈、透视、景别、机位、构图、景深和焦点。参数配合可见效果描述；故事板画面是定格状态，运镜轨迹留在调度图与动态镜头设计。下表为设计起点，可根据场景尺度和风格调整。

| 景别用途 | 光圈参考 | 关注点 |
|---|---|---|
| 大空间与空间参考 | f/8–f/16 | 建筑边界、近远关系与陈设清晰 |
| 中景 | f/4–f/5.6 | 主体关系与背景可读性 |
| 近景与细节 | f/1.4–f/2.8 | 焦点与前后层次，不裁掉关键结构 |

**规则96：场景概念图机位参考。**

| 空间类型 | 起始参数 | 选择理由 |
|---|---|---|
| Type A 小型封闭室内 | 24mm、f/8、平视 | 保留完整围合与室内尺度感 |
| Type B 露天院落 | 24mm、f/8、微俯至斜俯 | 看清入口与建筑围合 |
| Type C 半开放商铺 | 24mm、f/8、轻微俯视 | 兼顾入口、台面与内部纵深 |
| Type D 中大型室内 | 24mm、f/8、平视 | 表现空间轴线与结构层次 |
| Type F 开阔户外 | 35mm、f/11、高位斜俯 | 展示地形与远端关系 |

以上是五种常用情境，不宣称完整覆盖所有建筑类型。T5 的俯视与远景机位需适配屋顶遮挡；室内无法成立的垂直俯视改为室内斜俯。扩展机位可选85mm细节、35mm走廊纵深或50mm侧面平视，均补充实际画面内容。

**规则83/97/99：风格、材质与配色。** 先确认整体表现方法，再写光线色彩、材质、构图和镜头。人物固有外观归②，皮肤与渲染质感归⑤；空间结构归③，照明归⑤。同一项目使用一致的风格和配色命名，保留已有色号时不改写其名称。T6B 只保留结构与灰阶，不照搬彩色材质。

| 项目风格 | 材质与人物表现示例 | 光影与质感示例 |
|---|---|---|
| 写实/写实3D | 自然肤色、皮肤纹理、物理材质 | 柔和高光、细腻纹理或胶片颗粒 |
| 3D动漫 | 简化人物造型、动漫材质 | 清晰体积、可控高光与色彩层次 |
| 2D动漫 | 平涂色块、明确轮廓 | 赛璐珞分层、纯净色面 |
| 卡通 | 夸张比例、简化材质 | 大色块与明确明暗分区 |
| CG/混合风格 | 依项目定义选择材质 | 保持统一渲染和光照逻辑 |

映射为写作选项，不是模型行为保证。不要在同一段反复堆叠风格前缀，或强制加入与项目不符的相机品牌、胶片型号和写实术语。

## 故事板

**规则9/78：九格与分镜关系。** T6/T6B 右栏固定九格，九格是剧情关键帧，不等于九个物理镜头。每格标明所属物理镜头；第一格与分镜起始状态对应，第九格与结束状态对应。相邻格保留角色方位、视线、动作结果与环境痕迹，位置改变有前后依据。

**规则92：图板内容。** 整体横向两栏：右栏约70%–75%为三行三列等大剧情格，左栏约25%–30%为色彩设定、空间调度、按需特效细节。各格画面区按项目画幅，格下窄条只标 Shot 编号、节点和物理镜头编号。剧情画面不叠加调度线、参数或台词；这些信息留在左栏或文字交付。

调度图包含场景边界、定锚物、各角色起止位置与朝向、机位编号和轨迹图例。轨迹是调度图中的图示，九个剧情格只画静态瞬间。特效区呈现特效本身的结构/材质细节，不复制一幅完整剧情画面。

**规则101：设计审查。** 检查构图与视觉焦点、配色光影、姿态、角色特征和空间关系；T6B 额外检查黑白线稿与彩色参考的隔离。JSON 的 review.status 记录审查结果，当前脚本不替代审查、不拦截未审查状态；投入外部生成前按既定流程确认。

## 文本交付与 QC

规则21/25/79/80/95/102/105的共同部分以公共规则表为准，不在此重定义参考图数量、长度、层序或参数支持。尾约束写法见[公共示例](../../references/constraints.md)。

交付前人工核对模板字段、可见状态和设定；再用[QC 脚本](../../scripts/qc_check.py)检查实际提示词。它能发现部分占位符、机制词、素材声明、参数和文字问题；不能识别返图的结构错误、画风漂移或错误人物。模板源码中的占位符需填充，不能把模板源码当成品送检。
