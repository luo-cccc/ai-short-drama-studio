# 静态资产设计方法

模板字段与版式见[静态模板](templates.md)，层序、参数、画幅、继承和尾约束按[公共规则](../../references/rule-authority.md)。沿用[制作交接](../../references/production-workflow.md)的设定与资产ID；数据见[契约](../../references/project-data.md)，QC与切图见[本地工具](../../references/tools.md)。

## 角色与道具

同一角色形态、道具和场景使用稳定身份。人物描述以名称起始，保持脸型、发型、体型、服饰、鞋履与配饰一致；背面或侧面可见时补齐对应结构。局部特写只承载该视角需要的信息。

T1 角色板采用[模板1](templates.md#模板1角色完整视觉设定参考图)的两区版式，一次组织同一角色的完整全身三视图与四格面部特写。已有文字设定即可编写；目标角色图提供身份与可见造型，单独的画风图只提供指定表现方式，不能用另一角色的脸、体型或服装替代目标设计。不可见背面、鞋履与身体结构按既定年龄、体型和功能保守补全，并在提示词外说明推定部分。

左区三视图提供完整头身比例、正侧背服装结构；右区四格头像提供五官、发型和神态细节。两区只是展示倍率不同，骨相、头颈肩关系、服装连接和配色一致。分区、角度与对齐参数由模板1维护。

默认中性站姿与空手，用户的姿态或持物要求优先；非人类角色沿用既定解剖。图板不添加外加标题或标志，角色造型自带的文字、徽记与纹样按设定保留。

### 角色身份、状态变体与不对称特征

1. **固有外貌 DNA 跨镜保持**：`characters[].description` 与 `props[].description` 提供身份和默认造型。T1/T2完整记录对应资产；故事板与动态提示词按当前可见范围保留有辨识作用的特征，局部手足、背影不补不可见的正脸五官。换装、湿身和损伤按已发生的状态覆写，不能把默认服装文字当作回退依据。T6B只保留结构特征，排除颜色词；`qc_check.py`的特征词扫描是复核提示，不能证明身份或可见性正确。
2. **角色换装 / 战损 / 湿身 / 年龄变体（State & Costume Variants）**：
   - 同一人物换装、湿身、战损或妆容变化时保留原`CHAR-`身份，变体写入专用静态`PROMPT-`、本镜状态与交接记录；不能仅因造型变化新增说话角色ID，导致台词和声音归属割裂。年龄或物种变化若改变骨相，应按源稿明确保留与变化的特征，不强求骨相完全相同。
   - 有可用母图时，变体T1可绑定原角色T1或其`char_head_01_front.png`头像切片，并声明实际继承范围；没有图片时依据已确认设定编写，保留待生成状态。参考声明例如：`@图片1 参考目标角色[角色名称]的五官骨相、脸型比例与头颈关系。禁止继承原图服装状态、背景与表情。`正文再明确本次服饰、伤损或湿发状态。
3. **面部与服饰不对称特征防镜像翻转**：
   - 泪痣、单侧疤痕、单耳环、斜刘海、单肩披挂等不对称特征，必须在设定中写明**解剖左右**，并在具体分镜中换算为当前相机视角下的**画面左右或近远机位侧**（例：“角色解剖左眼角泪痣，正面平视时位于画面右侧眼角；左侧90度正侧脸特写时清楚可见；右侧脸朝向镜头时被遮挡不可见”）。

T2 聚焦一件可分离道具的单视角特写，说明形状、构造、材质、纹样和辨识细节。

T1/T2 使用纯白背景与均匀柔光，减弱戏剧性阴影及环境色，便于后续参考。背景放在场景层，照明放在风格层；物体仍保留可读的体积明暗。

## 空间与参考图

T3/T5 用基础可读光记录场所结构与材质，叙事光影留给镜头设计。T5、彩色 T6 与线稿 T6B 的继承范围分别按 R-REF-001 处理。

为出场角色分别绑定可识别的参考资产；空间复杂时结合概念图和多视角图，缺图时注明待生成项。素材位逐条声明继承与排除范围，并按实际平台能力分配。

### 九视角空间完整性与四向正反打对位绑定

先确定建筑围合、出入口、门窗、家具和定锚物的相对位置，再选择机位。各视角共享同一拓扑，逐格描述实际可见的边界、遮挡与物件位置，避免复制物品清单充当不同视角。封闭室内应保留墙体与屋顶关系，不能因机位选择变成剖面、沙盘或开放院落。

空间描述分三步：

1. **四向物理空间（Four-Wall Cardinal Topology）**：明确两条相反的主轴朝向、左翼、右翼及固定定锚物。按T5默认基线，视角1在入口墙一侧朝对面墙，视角7在对面墙一侧朝入口；其他场地可改轴，但须同步记录每格相机位置与朝向。不要只写含义不明的“正向/反向”，也不能把单向视图当成全向背景。
2. **相机位置**：说明所在物理位置与拍摄朝向。
3. **画面布局与 T5 切片对位绑定**：由前两项推导实际可见的前景、中景、背景与遮挡。T5用`scripts/slice_grid.py --mode grid --grid-kind spatial`切分，再按每格登记的机位和朝向选择切片；格号只表示九视角位置，不表示动作先后，视角1/9不自动成为视频首尾帧。反打背景按真实可见范围重写，可见的共同定锚物仍可保留。

T5 多机位统一使用建筑相对方位，不写罗盘方向。单视角可用画面方位或建筑方位，同一提示词保持一套参照。

### 场景扩图

区分已知结构与待补区域：已有门窗、陈设、连接关系、材质和配色保持不变，镜头外区域按已有结构延伸。新机位可以改变焦点，不能借此重新设计原场景。已知信息与推定区域写在设计说明中，返图后检查衔接。

T4/T5/T6/6B 正文清楚描述当前主体、空间与视角，参考行说明继承范围；多视角按可见内容分别写，不逐格重述完整场景档案。

## 镜头与风格

静态画面按需要选择镜头类型、焦距、光圈、透视、景别、机位、构图、景深与焦点，并配合观看效果描述。故事板呈现定格状态，运镜轨迹留在调度图与动态设计中。

| 景别用途 | 光圈参考 | 关注点 |
|---|---|---|
| 大空间与空间参考 | f/8–f/16 | 建筑边界、近远关系与陈设清晰 |
| 中景 | f/4–f/5.6 | 主体关系与背景可读性 |
| 近景与细节 | f/1.4–f/2.8 | 焦点与前后层次，不裁掉关键结构 |

### 场景概念图机位参考

| 空间类型 | 起始参数 | 选择理由 |
|---|---|---|
| 小型封闭室内 | 24mm、f/8、平视 | 保留完整围合与室内尺度感 |
| 露天院落 | 24mm、f/8、微俯至斜俯 | 看清入口与建筑围合 |
| 半开放商铺 | 24mm、f/8、轻微俯视 | 兼顾入口、台面与内部纵深 |
| 中大型室内 | 24mm、f/8、平视 | 表现空间轴线与结构层次 |
| 开阔户外 | 35mm、f/11、高位斜俯 | 展示地形与远端关系 |

以上参数是设计起点，按空间尺度和风格调整。T5 俯视与远景需考虑屋顶遮挡；室内无法成立的垂直俯视改为室内斜俯。扩展机位可选 85mm 细节、35mm 走廊纵深或 50mm 侧面平视，并补充实际可见内容。

### 材质与配色

先确定表现方法，再选择材质、光线色彩、构图和镜头。角色固有造型与配色放在主体层，皮肤及渲染质感放在风格层；空间结构放在场景层，照明放在风格层。同一项目使用一致的风格、颜色名称与已有色号。T6B 只保留结构与灰阶。

| 项目风格 | 材质与人物表现示例 | 光影与质感示例 |
|---|---|---|
| 写实或写实 3D | 自然肤色、皮肤纹理、物理材质 | 柔和高光、细腻纹理或胶片颗粒 |
| 3D 动漫 | 简化人物造型、动漫材质 | 清晰体积、可控高光与色彩层次 |
| 2D 动漫 | 平涂色块、明确轮廓 | 赛璐珞分层、纯净色面 |
| 卡通 | 夸张比例、简化材质 | 大色块与明确明暗分区 |
| CG 或混合风格 | 依项目选择材质 | 统一渲染和光照逻辑 |

风格措辞按项目取用，避免重复前缀、无关相机品牌或不适合平涂与卡通的写实术语。

## 故事板与九格时序采样

T6/T6B采用**同画幅满幅3×3九宫格关键帧图板**，整体外画幅与内部九格画幅统一使用项目主画幅（`project.aspect_ratio`），不添加顶部信息栏、左栏色卡/调度图、特效框或格下文字条。八岗位参数与运动轨迹留在分镜文档和块外说明；减少额外版式可增加画面有效区域，但仍须检查实际分辨率、文字和网格是否影响下游生成。

按[九格时序采样](templates.md#九格时序采样)标明时点、所属物理镜头及可见状态。九格不增加实际镜数；不足九个转折时可取持续动作和静止保持，不新增剧情或机位。审阅放大图另交，摄影变化先同步设计、segments、动态正文与预算。

## 交付与返图

交付前核对模板字段、构图、视觉焦点、配色光影、姿态、角色特征和空间关系，再用[QC工具](../../references/tools.md)检查实际提示词。

### 外部生图工具适配

| 平台 | 可测试的用途 | 投喂与参数适配规范 |
|---|---|---|
| **GPT Image** | T1角色板、T5空间图、T6/T6B故事板可先做小样，核对版式与逐格内容 | 将`@图片N`映射到真实输入图；自然语言画幅与接口支持尺寸一起设置，仓库末行`--ar`是数据协议，不视作接口参数。若接口无精确比例，说明实际生成尺寸及裁剪/补边方案，避免静默拉伸 |
| **Midjourney** | T2道具、T3/T4场景及单帧氛围图可先测试；多格任务重点检查身份与空间一致性 | 按所用版本区分普通图像参考、主体参考和画风参考，再将`@图片N`转换为对应附件或参数；不能把场景空间图统一转换为角色参考。参数名称、数量及画幅能力按实际版本核对，压缩文字时保留关键状态与继承范围 |

### 物理切图与下游视频衔接

生成T5空间图、T6/T6B故事板或T1角色板后，使用`scripts/slice_grid.py`按实际版式切分；切图保留源像素，不提升单格原始清晰度，内缩比例还须结合实际边线和主体位置核对：
- T5使用`--mode grid --grid-kind spatial`，切片只表示不同空间朝向。
- T6/T6B使用`--mode grid --grid-kind storyboard`；第1/9格分别记录起末态，能否作为目标模型首尾帧仍需核对风格、构图和身份。T6B线稿用于结构参考；需要写实或彩色高分辨率首尾帧时，使用**模板6C（T6C）**依据结构切片和角色/场景资产制作并检查匹配目标风格的全分辨率单帧。
- `t1`模式切出完整三视图区、三张全身图及四张面部图，用于对应的角色身份或造型参考；它们不自动具备剧情起末态。

返图逐张比对造型与空间，核对外画幅与单格画幅、文字及边线；T6B额外检查黑白灰表现。按实际模型能力选择单帧、结构参考或整板输入，整板参考仍有网格泄漏风险。参考图不能替代动态正文的摄影、动作和声音设计。

T1额外核对全身三视图与四格头像的数量、顺序和分区，以及基线、背发和衣领结构。程序只检查文本与数据，重复节点提示复核，实际返图仍需逐张核对。
