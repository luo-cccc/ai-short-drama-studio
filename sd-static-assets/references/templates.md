# 静态提示词模板

本文件定义`T1`–`T6`/`T6B`/`T6C`的提示词结构。使用时替换全部`[...]`占位符、删除未绑定的`@图片N`参考行，每条提示词输出为一个独立的`text`代码块。设计规则见[static-rules.md](static-rules.md)。
