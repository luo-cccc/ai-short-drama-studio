# 静态资产提示词

根据角色、场景、道具设定及参考图编写静态提示词，承接剧本交接和八岗位设计；独立任务直接按用途选择模板。造型、固有配色和参考范围须在提示词中明确。

## 模板选择

| 任务 | 模板 | 用途 |
|---|---|---|
| 角色完整设定 | T1 | 左55%完整带头全身正侧背三视图，右45%四格面部与微表情特写 |
| 道具设定 | T2 | 单主体微距参考 |
| 场景概念 | T3 | 纯净无字空间边界、陈设与定锚物 |
| 场景扩图 | T4 | 已有空间的相邻区域或新机位 |
| 场景多视角 | T5 | 同画幅三行三列无字纯净九视角 |
| 彩色3×3关键帧故事板 | T6 | 按已定摄影和行动采样的同画幅九格，用于审片及匹配目标风格的单帧参考 |
| 黑白线稿3×3关键帧故事板 | T6B | 同画幅黑白线稿九格，按真实节点采样，用于结构参考；不自动当作写实首尾帧 |
| 单帧关键帧／首尾帧重绘 | T6C | 将审定后的起末节点或结构切片展开为单画面满幅全分辨率目标风格关键帧，供视频首尾帧投产 |

## 制作与交付

1. 复用已有资产定义与ID，确定构图、造型、材质、光照和视觉焦点。
2. 从[模板库](references/templates.md)取对应模板，填入实际内容，删除未使用的参考行与条件区。
3. 将每条提示词放入独立text代码块，设计依据与素材映射置于块外。完整项目同步JSON；局部资产可直接交付提示词。
