# 静态资产提示词

负责 T1–T6/6B 的视觉设计和提示词文本。仓库未接入图片生成服务，引用素材位表示计划使用的参考图，不代表图片已生成。

## 输入与输出

输入为角色、场景、道具设定，以及需要时的已确认分镜设计、参考图和项目画幅。独立资产任务只补充当前资产必需的信息；全流程任务承接分镜模块的八岗位设计。

| 任务 | 模板 | 输出用途 |
|---|---|---|
| 角色完整设定 | T1 | 脸部特写、全身三视与细节面板 |
| 道具设定 | T2 | 单主体微距参考图 |
| 场景概念 | T3 | 空间边界、固定陈设与定锚物 |
| 场景扩图 | T4 | 在已有空间基础上补充相邻区域或新机位 |
| 场景多视角 | T5 | 同一空间的九视角参考图 |
| 彩色故事板 | T6 | 提案与审片 |
| 黑白线稿故事板 | T6B | 作为动态提示词的结构参考图 |

先说明构图、色彩光影、姿态与视觉焦点的设计决策，再将每条实际提示词独立放入 text 代码块。设计说明和素材位对照留在块外。模板占位符需填为实际内容，未使用的参考行删除。

## 工作方式

1. 根据资产用途选择模板，核对已有资产，避免重复定义同一角色或场景。
2. 完成静态设计：画面分区、造型、材质、光照、焦点与可见空间关系。审查按用户已约定的范围执行；已有授权覆盖的批次可继续。
3. 按模板写提示词，逐项核对角色、场景和道具与上游设定的一致性。
4. 完整项目更新 JSON 后导出；局部资产可直接交付提示词文本。实际生图和返图检查由外部工具及人工完成。
