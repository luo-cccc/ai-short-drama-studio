# 静态资产提示词

根据角色、场景、道具设定及八岗位分镜设计编写静态提示词（`T1`–`T6`/`T6B`/`T6C`）。

## 模板选择

| 模板 | 画幅 | 用途 |
|---|---|---|
| `T1` | `16:9` | 角色完整视觉设定图（左55%全身正侧背三视图，右45%四格面部与微表情特写） |
| `T2` | `3:4` | 单件可分离道具微距设定图 |
| `T3` | `16:9` | 场景全景概念图（纯净无人物、无文字标签） |
| `T4` | `16:9` | 场景扩图概念图（已有空间的相邻区域或扩展视角） |
| `T5` | 项目主画幅 | 场景三行三列无字九视角空间参考图（外画幅与单格画幅同构） |
| `T6` | 项目主画幅 | 彩色3×3关键帧故事板（同画幅满幅无字九宫格） |
| `T6B` | 项目主画幅 | 黑白线稿3×3关键帧故事板（白底黑线与三阶灰，结构参考） |
| `T6C` | 项目主画幅 | 单帧关键帧／首尾帧高清重绘参考图（供视频I2V/FLF2V首尾帧投产） |

## 编写与交付

1. 沿用项目稳定资产ID（`CHAR-`、`SCENE-`、`PROP-`），从[静态模板](references/templates.md)选取对应模板。
2. 替换全部方括号占位符，删除未使用的`@图片N`参考行，末尾保留一段30–50字[正向尾约束](../references/constraints.md)与`--ar`画幅声明。
3. 每条提示词放入独立的`text`代码块，素材位对照与设计说明置于块外。具体空间拓扑、变体锁脸与切图规则见[静态设计方法](references/static-rules.md)。
