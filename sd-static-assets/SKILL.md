# 静态资产提示词

根据角色、场景、道具设定及参考图编写静态提示词。全流程承接剧本交接和八岗位设计；独立资产任务直接按用途选择模板。

## 模板选择

| 任务 | 模板 | 用途 |
|---|---|---|
| 角色完整设定 | T1 | 脸部、全身三视与细节面板 |
| 道具设定 | T2 | 单主体微距参考 |
| 场景概念 | T3 | 空间边界、陈设与定锚物 |
| 场景扩图 | T4 | 已有空间的相邻区域或新机位 |
| 场景多视角 | T5 | 同一空间九视角 |
| 彩色故事板 | T6 | 提案与审片 |
| 黑白线稿故事板 | T6B | 动态视频的结构参考 |

## 制作与交付

1. 复用已有资产定义与ID，确定构图、造型、材质、光照和视觉焦点。
2. 从[模板库](references/templates.md)取对应模板，填入实际内容，删除未使用的参考行与条件区。
3. 将每条提示词放入独立text代码块，设计依据与素材映射置于块外。完整项目同步JSON；局部资产可直接交付提示词。
