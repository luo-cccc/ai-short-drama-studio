# 院门线索 · 前期交接示例

本文件演示《院门线索》单场（`COURTYARD-SCRIPT-r1`，`E01-S01`）到[project.json](project.json)的源稿映射与整场时间预算。

## 开发摘要

- 叙事路线：Type D信息与线索；导演风格为悬疑压迫流，视觉形态为写实。
- 局部变化：发现新锁 → 查看门框 → 取回铜钥匙。
- 制作规格：画幅`9:16`，共2个分镜（`SHOT-001`、`SHOT-002`），各`5.0`秒。
- 声音设计：院外风声与低音弦乐持续，门扇与钥匙轻响对应接触动作。

## 源剧本 · COURTYARD-SCRIPT-r1

### E01-S01 · 日 · 外 · 旧院门

出场人物：晚晴。可操作道具：铜钥匙。门扇、门闩与新铜锁在本示例中作为场景固定构件。

E01-S01-A01：△ 晚晴站在门前，面向入口右侧门扇。她看向新铜锁的亮边，眉心靠拢，指尖从身侧抬至锁旁，轻触门扇后停住。

E01-S01-D01：晚晴：门锁换过了。

E01-S01-S01：【音效：门扇在指尖轻触时发出细响，院外风声持续。】

E01-S01-A02：△ 晚晴看向门框缝隙，手指沿木框下滑，探入缝中，捏住铜钥匙的环柄向外抽出。她翻开手掌托住钥匙，眼睑稍抬。

E01-S01-D02：晚晴：钥匙还在这里。

E01-S01-S02：【音效：铜钥匙接触掌心，发出轻响。】

## 整场预算与分段

整场总轴为`0.0–10.0`秒（`SHOT-001`覆盖`0.0–5.0`秒，`SHOT-002`覆盖`5.0–10.0`秒）；各分镜内部均使用从`0.0`秒起算的局部时间轴。

### 整场0.0–10.0秒总轴

| 场内时间 | 片段及局部时间 | 操作、对白与反应 | 摄影、证据可读窗口及声音 |
|---|---|---|---|
| 0.0–0.6 | SHOT-001，0.0–0.6 | 目光落在新锁，眉心靠拢，操作手垂在身侧 | 门外左前方平视中近景，脸在左、锁在右；0.3–0.6s锁亮边清楚可辨；风声与弦乐持续 |
| 0.6–2.0 | SHOT-001，0.6–2.0 | 同一只手从身侧抬至锁旁 | 相机沿门扇向右短距横移，维持脸与锁同框 |
| 2.0–2.5 | SHOT-001，2.0–2.5 | 指尖轻触锁旁木面后停住，目光看锁 | 相机停稳，2.0s木面细响；2.0s起新锁与指尖持续清楚 |
| 2.5–4.0 | SHOT-001，2.5–4.0 | D01：“门锁换过了。” | 手位、目光与构图保持；对白与新锁可读画面并行 |
| 4.0–5.0 | SHOT-001，4.0–5.0 | 话音结束，嘴唇合拢，指尖仍贴锁旁木面 | 保留面部、新锁、停指与门框作为切出末态 |
| 5.0–5.3 | SHOT-002，0.0–0.3 | 从上一末态转眼看向门框缝口，手尚在锁旁 | 同一机位侧与站位承接，风声与弦乐连续 |
| 5.3–6.0 | SHOT-002，0.3–1.0 | 手指沿木框下滑至缝口 | 相机随手向右下短距跟移，眼睛与操作手同框 |
| 6.0–6.6 | SHOT-002，1.0–1.6 | 探入缝内捏住钥匙环柄 | 目光监控接触点，钥匙主体仍在缝内 |
| 6.6–7.2 | SHOT-002，1.6–2.2 | 捏住环柄向外抽出钥匙 | 相机继续跟手，钥匙由局部露出到完整出缝 |
| 7.2–7.5 | SHOT-002，2.2–2.5 | 翻掌托稳钥匙（局部2.5s接触掌心） | 相机向掌心缓慢跟近并俯摇；局部2.5s一次金属轻响 |
| 7.5–7.9 | SHOT-002，2.5–2.9 | 眼睑稍抬，完成见物确认反应 | 仍保留眼部与掌心同框 |
| 7.9–9.7 | SHOT-002，2.9–4.7 | D02：“钥匙还在这里。” | 局部3.2s落稳掌心近景，完整环柄与缺角齿口进入可读窗口 |
| 9.7–10.0 | SHOT-002，4.7–5.0 | 话音结束，掌心继续托住钥匙 | 掌心近景稳定至结束，门框留在背景右侧 |
