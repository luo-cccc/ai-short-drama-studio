# 导演风格

供故事开发与剧本审阅选择表达方向，随后交给八岗位设计转为镜头方案。

## 选择方法

沿用指定风格；需要建议时，根据观众期待、题材、回报方式与制作条件提出主方向，并说明选择目的。

**叙事风格**说明怎样呈现信息与情绪；**视觉形态**说明写实、2D、3D 等画面表现。二者分列组合，都市写实的方法也可用于动画。具体材质、造型、色彩与摄影另行设计。

## 九种可选方向

| 风格 | 视觉与表演 | 节奏与声音 | 适用目的与核对重点 |
|---|---|---|---|
| 卡点爽感流 | 用关键动作、结果特写和人物反应突出翻盘 | 在结果处加速或停顿，音乐与动作音效强调落点 | 逆袭、复仇、规则兑现；先建立筹码和代价，避免只剩重复反应 |
| 视听奇观流 | 用规模对比、空间调度和辨识清楚的特效呈现力量变化 | 起势、对抗、结果有轻重，声场区分动作与环境 | 玄幻、机甲、冒险；观众能看清谁采取行动、如何改变局势 |
| 悬疑压迫流 | 以遮挡、视线、空间距离和物证建立信息差 | 控制线索停留与揭示顺序，用声源和静默制造期待 | 推理、追查、隐藏身份；保留真相未知，同时让目标与风险可理解 |
| 情绪共振流 | 用微动作、关系距离和有选择的近景呈现态度变化 | 给反应与后果留出时间，环境音或配乐承接情绪 | 亲情、婚恋、守护；情绪转折有事件触发，不靠突然表态跳过关系过程 |
| 权谋克制流 | 以座次、出入权限、仪式和道具交接表达权力 | 停顿与调度承载交锋，制度性声音可作重复锚点 | 古装、家族、商战；克制表达仍有筹码、选择与局势变化 |
| 都市写实流 | 用具体生活空间、职业动作与自然反应建立可信度 | 保持行为和对话的自然时间感，声音来自可辨来源 | 职场、家庭、现实题材；职业与事实依据另行核实，流程服务人物目标 |
| 轻喜沙雕流 | 用景别反差、表演错位和场面变化呈现荒诞 | 用停顿、重复变体、快慢对照与音效组织笑点 | 喜剧、反套路；明确笑点前提与结果，重复时有变化，字幕梗另列后期任务 |
| 信息解说流 | 画面承接旁白提及的物件、证据和关系变化 | 以可理解的信息单元切换，口语旁白与画面对应 | 解说、翻案、知识型剧情；说明信息来源，避免念流程，图表和文字单独规划 |
| 高级文艺流 | 用留白、长镜头、隐喻和画内调度承载人物体验 | 节奏随信息与感受变化，允许声画对位与沉默 | 精品、品牌、作者表达；说明观众获得的变化，不以风格名称代替叙事依据 |

镜头时长、特写比例、动作强度与音乐密度依据当前戏选择。跨集或跨段切换风格时，记录范围、叙事原因及声音或视觉过渡。

## 风格卡

用自然语言记录当前所需项目：

- **范围与依据**：适用版本、集场及指定、沿用或建议的来源。
- **主方向与视觉形态**：表达目的、辅助方向、形态及已定的造型与色彩。
- **执行取舍**：构图、空间、表演尺度、节奏、关键声音，以及制作条件的影响。
- **切换与未决项**：变化位置、动机、过渡及尚待决定的选择。
- **文字需求**：字幕、UI、图表、信件等的用途、原文、出现位置与执行环节。

精确字幕与 UI 优先规划后期合成；画内招牌、信件和屏幕文字登记原文与用途。生成文字及参考继承的边界见 [公共规则](../../references/rule-authority.md)。

风格卡随剧本进入 [制作流程](../../references/production-workflow.md)。审阅时检查选择是否服务剧情、变化有无动机；信息、因果或执行问题按 [剧本审阅](script-review.md) 登记，单纯风格偏好列为建议。
