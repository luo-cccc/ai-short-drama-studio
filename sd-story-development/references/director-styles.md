# 导演风格

供故事开发与剧本审阅确定视听表达方向，交接给八岗位分镜转化为具体镜头方案。**叙事风格**（如何组织信息与情绪）与**视觉形态**（写实 / 2D / 3D）分别记录。

## 九种导演风格

| 风格 | 视觉与表演 | 节奏与声音 | 适用题材与核对重点 |
|---|---|---|---|
| 卡点爽感流 | 关键动作、结果特写与人物反应突出翻盘 | 在结果处加速或骤停，音效与配乐强调落点 | 逆袭、复仇、规则兑现；先建立筹码与代价，避免重复单一反应 |
| 视听奇观流 | 规模对比、空间调度与清晰特效呈现力量变化 | 起势、对抗、结果层次分明，声场区分动作与环境 | 玄幻、机甲、冒险；确保看清行动主体与局势变化 |
| 悬疑压迫流 | 遮挡、视线、空间距离与物证建立信息差 | 控制线索停留与揭示次序，用声源和静默制造张力 | 推理、追查、潜伏；保留真相未知，同时让当前目标与风险可辨 |
| 情绪共振流 | 微动作、关系距离与克制近景呈现态度转变 | 为反应与余韵留出时间，环境音与配乐承接情绪 | 亲情、婚恋、守护；情绪转折须有事件触发 |
| 权谋克制流 | 座次、出入权限、礼仪与道具交接表达权力关系 | 停顿与调度承载交锋，制度性声响作为锚点 | 古装、家族、商战；克制表面下须有明确的筹码与局势变化 |
| 都市写实流 | 具体生活空间、职业动作与自然反应建立可信度 | 保持行为与对话的自然时间感，声源真实可辨 | 职场、家庭、现实题材；操作细节服务于人物目标 |
| 轻喜沙雕流 | 景别反差、表演错位与场面变化呈现荒诞 | 停顿、重复变体、快慢对比与音效组织笑点 | 喜剧、反套路；明确笑点前提与结果，字幕梗单列后期任务 |
| 信息解说流 | 画面承接旁白提及的物件、证据与关系变化 | 按信息单元切换，口语旁白与画面物证严格对应 | 解说、翻案、知识剧情；明确信息来源，图表与字幕单独规划 |
| 高级文艺流 | 留白、长镜头、隐喻物象与画内调度承载体验 | 节奏随人物感受变化，善用声画对位与沉默 | 精品短剧、作者表达；明确每场观众获得的信息或情绪变化 |

## 风格卡要素

- **适用范围**：剧本版本、集场范围及主/辅风格方向。
- **视觉形态与基调**：写实 / 2D / 3D形态、核心造型与光色基调。
- **视听执行取舍**：景别偏好、机位运动尺度、表演克制或外放程度、关键声源设计。
- **文字与后期需求**：画内文字（招牌、信件、屏幕）与后期叠字（字幕、UI、花字）的内容、位置及实现方式。
