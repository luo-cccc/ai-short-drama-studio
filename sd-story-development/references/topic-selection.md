# 选题与叙事方向

比较点子、梗概或 IP 方向，说明给谁看、期待什么回报、靠什么事件兑现，以及制作条件带来的取舍。

## 输入与判断依据

从材料中提取故事范围、目标观众、核心人物、保留项、篇幅与制作条件；未定条件只有在影响候选比较时才需补齐。

来源事实附材料位置或出处；新增人物、冲突和事件标为创作提案；市场热度、平台要求及未证实的职业、文化事实列为待核验。引用外部要求时注明来源与日期。

多个候选使用同一组项目条件比较，以事件和取舍支持建议，不凭印象给市场结论或分数。

## 故事核与题眼

用简短自然语言说明：谁要什么、什么阻止他、失败会失去什么。再描述主要回报：真相重组、关系确认、能力兑现、处境逆转或喜剧反差等。

从以下角度判断题眼能否落地：

1. 主角的身份、选择或处境怎样改变事件？更换主角的测试可帮助发现其具体作用；群像、寓言等按自身结构判断。
2. 核心设定造成什么实际事件？为“身份错位”“特殊规则”等题眼设计一次可被感知的结果。
3. 开篇提出什么问题或欲望，作品何时以事件回应？
4. 人物选择、冲突机制或回报方式怎样区别于其他候选？

## 叙事路线 Type A/B/C/D

路线说明故事靠什么推进，与真人、2D、3D、画幅及美术风格分别选择。可记录主路线及辅助路线。

| 路线 | 主要推进方式 | 适配时核对 |
|---|---|---|
| Type A：奇观与动作 | 空间、动作、能力或环境变化带来事件与回报 | 变化是否改变局势；动作因果是否可读；复杂变化是否有可行的简化方案 |
| Type B：人物与关系 | 人物选择、现实利益、关系或制度冲突推进 | 动机与风险是否相称；关系变化有无行动依据；职业与制度事实哪些待核验 |
| Type C：喜剧与反差 | 认知错位、行为反差、误会或荒诞规则形成笑点 | 反差由谁触发；规则是否自洽；重复情境是否带来新变化 |
| Type D：信息与解说 | 线索、证据、旁白组织或认知重组推进 | 信息来源是否清楚；观众能否跟上已知与未知；解说是否有对应画面或声音依据 |

悬疑可借助任一路线：记录观众知道什么、追查什么、承担什么风险，区分有意隐瞒与叙述缺口。

## 表达与制作适配

路线难以兑现题眼时，给出调整方案：把规则变成一次选择及其后果；把大场面转为局部接触、环境反应或事后证据；把复杂信息分给有动机的行动。比较调整前后的核心回报，说明简化保留了什么、损失了什么。

需要表达建议时读取 [导演风格](director-styles.md)，说明节奏、声音、表演与制作量的取舍。成本依据实际场景、资产、动作和返修条件估计。素材改编边界或发布要求影响方案时，记录具体问题及可选表达。

## 可填选题卡

按任务保留有用栏目；候选多时可用表格比较。

```text
项目或候选名：
材料与保留项（来源位置）：
一句话故事核：
主要观众期待与回报：
叙事路线及理由：
题眼兑现事件（原有／提案）：
区别于其他候选的选择：
篇幅与制作条件（已知／假设／待定）：
表达或风格建议（需要时）：
待核验的事实、素材或发布要求：
建议：保留／修订／换方向
依据、取舍及下一步：
```

已有故事进入 [故事优化](story-optimization.md)；需要展开成场景剧本时交给 [编剧模块](../../sd-scriptwriter/SKILL.md)。建议“保留”只表示选题判断。
