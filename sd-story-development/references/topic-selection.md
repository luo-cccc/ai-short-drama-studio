# 选题与叙事方向

比较候选点子、梗概或IP方向，明确目标受众、核心回报、兑现事件与制作取舍。

## 1. 故事核与题眼检验

用一句话概括：**谁要什么 — 什么阻止他 — 失败失去什么 — 靠什么事件兑现何种回报**（真相重组、关系确认、能力兑现、处境逆转或喜剧反差）。

从四个问题检验题眼能否落地：
1. 主角的特定身份或处境如何改变事件走向？
2. 核心设定触发了哪一次具体可感知的行动与后果？
3. 开篇提出了什么悬念或诉求，何时以具体事件回应？
4. 人物选择或冲突机制与同类题材有何差异？

## 2. 叙事路线（Type A/B/C/D）

叙事路线定义故事推进方式，与写实、2D、3D视觉形态及美术风格分别选择：

| 路线 | 推进方式 | 核对重点 |
|---|---|---|
| Type A：奇观与动作 | 空间、动作、能力或环境变化带来事件与回报 | 变化是否改变局势；动作因果是否可读；复杂场面的简化方案 |
| Type B：人物与关系 | 人物选择、利益、关系或制度冲突推进 | 动机与风险是否匹配；关系转折有无行动依据 |
| Type C：喜剧与反差 | 认知错位、行为反差、误会或荒诞规则制造笑点 | 反差由谁触发；规则是否自洽；重复情境是否有递进 |
| Type D：信息与线索 | 线索搜集、物证、旁白组织或认知重组推进 | 信息来源是否清楚；已知与未知边界是否明确；画面是否有对应物证 |

需要视听风格建议时结合[导演风格](director-styles.md)评估场景、资产与动作成本。

```text

建议：保留／修订／换方向

```
