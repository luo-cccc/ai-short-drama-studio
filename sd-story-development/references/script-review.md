# 剧本证据审阅

审阅当前剧本，定位问题、提出修法，并复核改稿结果。场景和对白的修订交给 [编剧模块](../../sd-scriptwriter/SKILL.md)。

## 范围与证据

登记源文件、版本和本次范围：全剧、指定集数、单场或专项。只提供前三集时，后续回收和连载结果列为未验证。

证据使用集场号、段落 ID 或文件行号，附原稿版本；改稿后更新定位，旧报告继续指向旧稿。每项意见区分：

- **证据**：位置、必要短摘或可核对的动作/台词事实。
- **判断**：证据如何影响当前叙事目标。
- **未验证项**：材料缺失、范围未覆盖或依赖外部核实的内容。

## 按问题选择维度

| 维度 | 核对内容 | 判断依据 |
|---|---|---|
| 叙事 | 目标、阻力、因果、局面变化是否可追踪 | 比较场前与场后状态，定位关键转折的准备和结果 |
| 信息 | 观众知道什么、暂不知道什么，是否理解正在追求的目标与风险 | 标出信息首次出现、重复解释和必要证据；悬疑可保留真相未知 |
| 动机 | 人物选择是否符合已知信息、利益、关系与所付代价 | 核对重大行动的诉求、手段、风险，以及态度变化的触发事件 |
| 回报 | 本范围承诺了什么，交付了什么，情绪和信息如何变化 | 定位可见结果、关系推进、认知变化或局部收束，不把所有回报限为打脸 |
| 连载 | 前后集是否连接，冲突是否升级，伏笔与关系是否有后续接口 | 仅对已提供剧本与大纲建立事件链；未提供的后续标为待验证 |
| 风格 | 叙事方式、表演、节奏、声音是否服务约定风格 | 对照 [风格卡](director-styles.md)，区分有意转变与无动机变化 |
| 制作可行性 | 行动能否被看见、听见或表演，空间与道具状态能否交接 | 标出资产变化、复杂互动、必要文字和声音；提出拆分或后期方案 |

节奏依据项目目标、篇幅与实际动作和台词承载量判断；文学场次和单集不套用生成片段时限。

## 问题、修法与复审

需要追踪的实际问题记录问题 ID、优先级、证据、判断、修法和重审标准。

| 优先级 | 使用条件 | 处理方式 |
|---|---|---|
| 阻断 | 核心因果、关键动机或执行事实缺口使本范围无法可靠制作 | 返回故事优化或剧本修订，解决后再交接受影响内容 |
| 重要 | 本范围能够理解，但回报、关系变化或表达明显受损 | 提供可执行改法，说明影响的场次、台词与设定 |
| 建议 | 存在更合适的风格或工艺选择 | 说明收益与取舍，不以个人审美否决内容 |

修法写成可检查的变化。例如“公开指认前补出物证取得过程”，复审核对“能否定位物证来源、持有人和指认结果”。故事核、冲突链或人物关系的问题可回到 [故事优化](story-optimization.md) 重构。

编剧完成修订后，逐项比较新稿与原问题，记录已解决、仍存在或暂不处理及依据。只请求审阅时交付意见；不把修订提案当成原稿已改。

## 审阅结论

结论注明适用版本和范围：

- **可交接**：本范围的制作阻断项已解决，剩余事项及其影响已明确；仅对该范围成立。
- **待修订**：已有材料足以定位问题，但需要完成列明的修改。
- **待补材料**：缺少判断当前范围所必需的内容；写清所缺材料、影响和可继续的部分。

定稿、用户确认及制作交接按 [制作流程](../../references/production-workflow.md) 记录；程序校验范围见 [项目数据说明](../../references/project-data.md)。

## 用户要求量化时

先定义用途、范围、维度、分值与权重、证据要求及结论映射。一个缺陷只按约定入口扣分，多维引用同一证据时区分各自判断。

材料不足的项记为未评；缺项影响可比性时不合成总分。分列事实计数、审阅判断与计算结果，避免把项目评分解释成市场预测或平台认证。
