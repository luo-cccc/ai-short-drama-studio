# 剧本证据审阅

定位现稿缺陷、提出可执行修法并复核改稿结果。

## 1. 证据与审阅维度

问题须绑定源文件版本与集场号、段落ID或行号，区分**证据**（原稿动作/台词事实）、**判断**（对叙事或制作的影响）与**未验证项**（未提供场次或待核实事实）。

| 维度 | 核对重点 |
|---|---|
| 叙事因果 | 场前场后状态是否变化，转折是否有前置准备与后续结果 |
| 信息揭示 | 观众已知与未知是否清晰，关键物证与信息首次交代是否明确 |
| 人物动机 | 重大选择是否符合角色已知信息、利益、关系与所付代价 |
| 回报兑现 | 本范围承诺的逆转、解谜、关系推进或情绪释放是否落地 |
| 连载衔接 | 前后集冲突是否递进，伏笔与悬念是否有回收接口 |
| 导演风格 | 视听节奏、表演与声画设计是否符合[导演风格卡](director-styles.md) |
| 制作可行性 | 动作、空间、道具状态变化与必要画内文字能否在镜头与后期中实现 |

## 2. 问题分级与修法

| 优先级 | 定义 | 处理方式 |
|---|---|---|
| 阻断 | 核心因果断裂、关键动机缺失或执行事实缺口导致无法可靠制作 | 退回故事优化或编剧修订，解决后再进入分镜制作 |
| 重要 | 故事可理解，但回报力度、人物关系或视听表达明显受损 | 给出具体到场次与台词的修改方案 |
| 建议 | 存在更优的节奏或工艺替代方案 | 说明收益与取舍，供主创选择 |

修法须写成可核验的具体变化（如“公开指认前补出物证取得动作”），复审时逐项核对新稿标记“已解决／仍存在／暂不处理”。

## 3. 审阅结论

- **可交接**：本范围无制作阻断项，剩余事项及影响已明确，可作为制作基线。
- **待修订**：需先完成列明的阻断或重要修改。
- **待补材料**：缺少判断当前范围所必需的设定或场次。

若用户要求量化打分，须先明确维度权重与唯一扣分入口，材料缺失项记为“未评”，不虚构总分。
