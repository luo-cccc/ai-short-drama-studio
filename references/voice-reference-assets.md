# 角色声音参考资产

声音资产用于向视频模型提供角色的声音身份参考。制作流程为：声音设计与试听 → 选定母版 → 准备模型投喂副本 → 绑定当前分镜 → 生成视频 → 返片听审。语音工具可用于制作试听和参考文件；正式台词仍由视频模型依据镜头正文生成。本仓库交付规范、数据与提示词，不调用语音或视频服务。

## 声音设计与试听

声音卡记录可听辨的稳定特征：年龄听感、音区、音质、语言口音、咬字和句尾习惯。与经常同场的其他角色一起比较，避免只孤立选择一段好听的声音。`characters.voice`保留简短声线摘要；完整声音参考记录使用独立的`VOICE-`资产。

声音来源可为已有音色库、文字声音设计或来源明确的录音。向上游工具提供声音描述与试听文本时分开交付，按实际接口组装；不要把设计说明混入纯朗读文本。可对少量候选使用相同普通语句试听，再用实际需要的疑问、低声或激动表达核对身份连续性。

声音设计交接示例：

| 项目 | 晚晴的设计草案 |
|---|---|
| 稳定身份 | 青年女性，中音区，清亮偏实声；普通话，字头清楚，短句尾音自然收住 |
| 试听表达 | 自然常态陈述，带轻微疑问变化，表达克制，避免夸张哭喊 |
| 试听文案 | 雨刚停，窗外还有一点风。你先坐一会儿，我把事情慢慢说清楚。 |
| 与其他角色区分 | 和同场角色比较音质、咬字与句尾，必要时修改候选 |

以上文案只是参考样片内容，不增加故事事实。试听文案可保存在可选的`audition_text`中，与声音描述及`notes`中的上游制作说明分别交付；取得母版后，将实际录音的准确文字保存到`master.transcript`，不以计划文案冒充实际转写。`audition_text`不进入`dialogues`或动态提示词代码块。

每个角色先选定一条常态身份母版：单人、清楚、连续、自然说话，减少音乐、其他人声、环境噪声、明显混响与夸张表演。录音开头应尽快进入有效发声，避免模型截取到长静音。试听文本不必自报角色姓名，也不必采用本镜的剧情关键句。

常态声线选定只说明该范围已试听；特殊表演仍需验证。情绪样片及童年、长期伤声等声音变体按剧情需要补充，注明适用范围，不为每个角色预建整套情绪库。

## 母版与投喂副本

- 母版保留完整音频、准确转写、来源和版本，选定后不自动用后续视频提取的声音替换。
- 投喂副本按具体视频模型的音色参考能力、格式、数量和时长要求裁剪或转换，记录源区间和文件指纹。裁剪不改写声音身份，不把某个平台的短音频限制当通用规格。
- 未制作的声音保留待制作状态和设计文字，不登记虚构文件，也不分配已上传音频槽。
- 供应商的音色ID可作为来源信息；视频投喂以实际文件与角色归属为准。

字段见[声音数据契约](project-data.md#角色声音参考数据)，文件检查命令见[本地工具](tools.md#校验)。模型配置记录本次采用的能力与依据；未核实的配额明确保留未知。

## 角色、声音与素材槽

T7/T8/T9仍分别表示视觉参考模式；声音参考是独立的可选输入，因此无参考图的T7也可带声音参考。声音文件只用于动态提示词，不作为静态图像素材。

每条实际声音参考绑定到具体角色；旁白声音可独立登记。按需加载本段发声角色、画外角色、OS或旁白的声音，安静出场的角色不默认占用音频槽。多人主要对白使用分别可识别的声音参考及明确说话人；模型容量不足时调整分段或记录未覆盖范围，不把多人混音视为已完成角色分配。

素材位在当前提示词内与图像参考统一编号，不能把同一个槽同时分给图片和声音。下面是仓库内部的声明示例；实际平台的图片/音频编号及上传方式按模型适配，提示词中的声明不等于已经上传文件。

```text
@素材4 参考角色晚晴的声音身份、音色、口音与咬字。禁止继承样片台词、情绪、语速、背景声音。
```

角色正文可明确外观与声音各自的来源，例如“角色晚晴：外观参考@素材1，声音身份参考@素材4”，再补模板要求的外观正文。参考声明和角色名称、`VOICE-`归属及本镜说话人保持一致。

声音参考传递稳定身份；本镜的情绪、重音、停顿、语速和声画关系写在实际镜头中。默认沿用常态母版，OS等表达变化不自动建立新声音身份。

## 样片文字与正式台词

样片转写用于试听、追溯和识别参考内容，留在声音资产记录中。它不进入`dialogues`、第四章正式对白表或动态正文的台词引号，不参与剧情台词认领。不得把样片文案粘贴进镜头冒充本镜对白。

正式台词、OS和NAR继续来自采用的剧本，保持说话者、字词、顺序及已有时段；本镜表演在镜头中描述。声音文件的长度不是本镜配音时长，也不替代[整场预算](scene-timing.md)。

## 返片听审与回改

生成视频后核对：

- 角色归属是否正确，多人接话是否串声。
- 同一角色与选定母版、相邻镜头是否维持可辨识的声音身份。
- 正式台词是否准确，是否串入参考样片的文字。
- 本镜表演是否成立，是否被样片的情绪、语速或背景声带偏。
- 嘴部动作、对白、动作节点和片段时长是否对应。

结构QC检查归属、绑定、配额和版本；显式文件检查核对指纹。声音身份、串读、表演与声画关系由返片确认，尚未听审时保留未验证状态。

声音母版或投喂副本变化时，增版声音资产并重做受影响的动态提示词与绑定，再捕获依赖、QC和导出。已验收片段可作人工对照，母版仍以选定版本为准。
