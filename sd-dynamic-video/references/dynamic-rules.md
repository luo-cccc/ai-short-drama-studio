# 动态设计与声音方法

本文是镜头与声音的写作参考，不是生成模型的官方规范。跨模块层序、时长、时间戳、参考继承、参数和约束只由[公共规则表](../../references/rule-authority.md)定义；实际格式见[动态模板](templates.md)。规则编号保留用于引用。

## 时长与剧情承载

**规则2/6/22/25/77：范围与结构。** 按 R-STRUCT-002、R-SPACE-001、R-TIME-001 和 R-LENGTH-001 执行。时长由剧情、动作、换景与声音共同决定，不用固定字数判断是否能容纳。一个时间区间只定义一次，不给同一镜头并列冲突的时间表。

**规则22a：局部时间轴。** 当前数据契约中一个 shot 对应一条动态 prompt，segments 从该 shot 的0秒开始；每镜配音表也使用这条局部时间轴。跨镜总时间需由后续剪辑累加，仓库没有全局音频时间线或混音执行器。

**规则22b：物理镜头与动作节拍。** 每个物理镜头一个镜头块；同一块可包含连续动作或角色对话。不要按台词条数拆镜。为动作、停顿、反应和完整台词留出时间，超出承载量时拆分分镜。

**规则25a：语速用词。** 为便于项目内统一，使用急促、快速、匀速、平缓、缓慢、凝滞六类描述。QC 对部分非标准语速词给提示，不能证明实际语速符合设计。

**规则25b/29a：台词来源。** 继承剧本台词与说话角色，允许标点及空白调整，不替换、增删文字。若台词过长，优先调整镜头与分镜时长；需要删改时回到剧本修改，再重做下游。不能在动态环节以“压缩台词”为由绕过原文对账。

**规则64/65：节奏选择。** 结合铺垫、危机、反转和悬念分配时间，比例依项目而定。动作高潮可通过短促动作与停顿交替表现，文戏保留可读的表情与反应；过渡镜也不硬编码为固定秒数。

## 镜头、动作与空间

**规则30/30a：设计输入。** 动态提示词承接八岗位设计：情绪目标对应叙事决策，风格对应光影与材质，镜头块对应摄影、动作、空间、声音和特效。JSON 记录设计与审查状态；程序校验不证明设计已审查或画面能实现。

**规则42/57/58：运镜。** 每块明确景别、运动方式、机位、构图、透视/前遮挡、景深和焦点。一个主要运动服务一个叙事目的；运动的转折有可见动机。根据需要使用固定、推拉、摇移、跟拍、升降、环绕或手持，不强制所有镜头使用同一运动或速度。

**规则74：信息优先级。** 先写完整主体动作链与环境变化，再补必要的表情、特效与服饰细节。动作被微观描述淹没时，删去不影响剧情的细节，不删承接动作和结果。

**规则44/75：表情与表演。** 在情绪转折处选取能看见的物理反应：眉弓/眉间、眼睑、瞳孔与视线、嘴部、下颌。五部位是观察清单，不要求每个镜头逐项写满。描述表情变化的触发动作与停顿，避免只用“绝望”“愤怒”代替画面；④情绪目标和声音描述可保留情绪词。

**规则46：肢体连续性。** 大幅转头要考虑肩躯干联动，抬手需有肩臂路径，下蹲或起身需有重心与支撑。动作接触点、握持关系、前后遮挡和受力反应一致。不要把任意角度阈值写成人体运动定律；参数范围按 R-PARAM-001。

**规则76：位置与视线。** 镜头1建立出场主体的位置、朝向、视线与姿态，后续用动作解释变化；收束时交代空间落点。人物看到/触及目标前，给出目光或手部路径。重复静态站位说明不会代替连续动作，也不能保证模型不漂移。

**规则76a：镜头块语言。** 画面部分写摄影与运动、可见动作、可见表情、空间与环境动态；声音部分另按音频方法写。设计理由、心理推断、因果解说和观众评价留在设计章，不混入可复制提示词。

**规则76b：交付清理。** 按 R-VISUAL-001 清理未填占位、管理/机制标签和跨模板指令。真实提示词自包含：参考行说明图像继承范围，正文写当前画面，不写“参见T6”“与上镜完全相同”。抽象情绪禁词不覆盖④情绪目标和声音段。

### 转场与收束（规则13）

首镜状态与故事板第一格、末镜状态与第九格使用同一份镜头设计核对。上下镜的转场成对记录在 transitions.incoming/outgoing，并在实际镜头中写出可见变化。

| 方式 | 上镜出段 | 下镜入段 |
|---|---|---|
| 渐暗/渐白 | 画面逐步被黑/白覆盖 | 从同一底色逐步显出画面 |
| 闪切 | 瞬间被强光或黑场覆盖 | 从对应底色迅速恢复 |
| 焦点变化 | 主体逐渐失焦 | 从虚化中重新聚焦 |
| 摇甩 | 运动形成有方向的流动模糊 | 沿匹配方向减速稳定 |
| 光源遮盖 | 过曝扩散至覆盖画面 | 光效收敛，露出下镜内容 |
| 遮挡 | 人物/道具遮满画面 | 对应遮挡移开 |
| 出入画 | 主体走出边缘 | 按衔接关系进入画面 |

转场时长按动作和叙事需要安排，不统一预留固定秒数。对白桥接、环境声延续与背景音乐也需核对，仓库不自动制作转场或混音。

### 形变设计（规则46b）

涉及变身、年龄变化或物种转换时，先设计连续可见的颜色、轮廓、材质与体量变化。衣物、骨架和皮肤同步，四肢与接触物避免互穿；用分部位递进或稳定停顿降低信息负担。光效可强化变化，不用它隐藏缺失的动作。跨度过大时可选择遮挡或剪辑过渡，但要把实际采用的方案写清，不宣称文字能保证连续形变成功。

### 对抗与介质特效

对抗戏的节拍应能看见攻守变化：进攻、应对、计划被打断、结果与代价。回合数量服从当前剧情，不强制每场三回合或主角固定吃亏次数。重击可给短暂停顿与环境反应，节奏不靠持续加快镜头表现。

若设计的是水、火、烟、气等介质，写介质本身的流动、厚薄、破散与接触，不因招式名称带“剑”就默认为金属。发光、自发光和实体化按项目设定选择，不能把一种题材美学设为所有法术的硬规则。

## 风格与参考资产

**规则52/71/78/80/83D/85/87：层级边界。**

- ②写角色固有造型，③写空间与物体，⑤写风格、光影色彩和渲染质感；同一信息避免多处重复。
- ⑤以项目整体风格开头，叙事照明按主光、辅光、轮廓光、环境光说明方向、色温或冷暖、强弱关系及效果。数值光比改为可见的明暗关系。
- 动态场景/故事板参考按 R-REF-001 继承空间与静态状态，叙事光色由文字指定。素材位还需与实际上传图核对。
- 画质描述表达目标，不证明模型输出分辨率、色深或相机特性；仓库不设置这些生成参数。
- 配色、材质和光影术语与项目风格一致；不要把写实术语强加到平涂或卡通，也不因加入品牌名称假定达到某种效果。

人物名称在角色行前置，分别描述。声线、参考资产和镜头中说话人使用同一角色身份。

## 声音脚本（三层四类）

环境音和 BGM 在镜头块前各写一行；动作音效、台词、OS 和 NAR 归属相应镜头。声音是自然语言设计，不是渲染与混音结果。

| 类型 | 写法与职责 |
|---|---|
| 环境音 | 声源、动作与声音质感，说明持续或中断 |
| BGM | 乐器、节奏、情绪及进入/收束，衬托对白 |
| 动作音效 | 紧跟触发动作，区分碰撞、摩擦、破裂等具体声源 |
| 角色台词 | 声线、表达、语速、语气后接原文引号台词 |
| OS 内心独白 | 标记 OS，保留该角色核心音色；设计为非嘴部发声 |
| NAR 旁白 | 标记 NAR，作为叙述者独立声线 |

**规则5/17/17a/17b/28/29/66：声音与画面协同。** 台词与动作、停顿、表情形成节拍；环境和音乐为对白让位。不要为每句话追加一整套表情动作。字幕/画内文字按用户需求确认，明确内容、位置和造型；默认提示词使用无字幕。不同分镜的表格按各自局部时间轴记录，不复制一份未经对齐的全局表。

角色声线沿用 characters.voice；同一角色的 OS 只改变表达方式，不另换一个身份。旁白声线需能与角色区分。字幕、口型、声画同步及 OS 发声方式须由外部工具与返片检查确认，不能仅凭标记认定已实现。

### 语速、情绪与标点参考

语速只用自然语言，不把“每秒几字”作为模型参数。为台词预留空间时可以人工朗读计时；超时回到镜头和剧本设计处理。

| 情绪方向 | 语速起点 | 表达方式示例 | 标点用途 |
|---|---|---|---|
| 愤怒/兴奋 | 急促 | 气息短促、重音清楚 | ！强调，——中断 |
| 悲伤/疲惫 | 缓慢 | 气息不足、尾音渐弱 | ……迟疑或留白 |
| 恐惧/紧张 | 快速 | 换气频繁、短句断续 | ，断句，？疑问 |
| 果决/陈述 | 匀速 | 咬字清楚、句尾收束 | 。结束完整语义 |
| 温柔/释怀 | 平缓 | 气息绵长、尾音柔和 | ，自然衔接，。收束 |
| 犹疑/低语 | 凝滞 | 轻声、语句间留白 | ……停顿，？悬问 |

这些是设计选项，不是情绪与语速的唯一对应关系。标点的精确停顿时长及百分比变化不由仓库实现，也不作平台能力承诺。

### 项目标点约定

QC 对引号中的顿号、波浪号、方引号、单个省略号或 ASCII 三点、叠加感叹/问号等给错误；英文 --/--- 破折号在正文中也会被拒绝。用中文逗号、双引号、六点省略号“……”和破折号“——”等替换。正文顿号仅给建议。这是当前检查器的写作约定，不声称某模型不能识别这些字符。

## 交付前核对

- 用[QC](../../scripts/qc_check.py)检查完整项目或实际提示词；时间戳、台词、素材引用和依赖状态按当前实现对账。
- 尾约束和占位清理引用[公共写法](../../references/constraints.md)，不重复定义长度。
- 实际摄影效果、表演、空间连续性、声音时长、口型与审美质量由人工/外部生成流程核对。
- 模板源码含写作占位符，不当作成品运行 QC。
