# 动态设计与声音方法

动态提示词承接摄影、动作、空间、声音与特效设计。字段见[动态模板](templates.md)，格式见[公共规则](../../references/rule-authority.md)，交接见[制作流程](../../references/production-workflow.md)，数据见[契约](../../references/project-data.md)，命令见[本地工具](../../references/tools.md)。

## 时长与剧情承载

一个 shot 对应一条动态 prompt，segments 和每镜配音表使用从零开始的局部时间轴；跨镜总时间由后续剪辑累加。每个物理镜头使用一个镜头块，可包含连续动作或多句对话。

先按[整场预算](../../references/scene-timing.md)排剧情、动作、换景、完整台词、停顿、反应与证据阅读，再按承载量拆分分镜。同一时刻的动作、对白和环境声共用时间，先后依赖则顺序计算。一个区间只定义一次；落实到片段的镜内阶段与正文使用对应SHOT的局部时钟，场内总轴另存映射。超出承载量时延长或增拆分镜；需要删改台词时回到源稿和交接修订，再更新下游。

结合铺垫、危机、反转和悬念选择节奏。动作高潮可用短促动作与停顿交替，文戏保留可读反应，过渡镜也按叙事需要安排。

## 镜头、动作与空间

### 运镜与信息优先级

每块明确景别、运动方式、机位、构图、透视或前遮挡、景深和焦点。根据需要使用固定、推拉、摇移、跟拍、升降、环绕或手持；一个主要运动服务一个叙事目的，转折有可见动机。

把摄影写成具体过程：当前观察谁或什么，摄影机相对哪个人物与场景锚点，从哪里朝哪里拍，起幅能看见什么，何时启动、沿什么路径和节奏移动，最终落到什么可见关系以及是否稳住。固定镜头也写清主体、机位朝向、画内关系变化与结束取景；单写轻推、跟拍或固定不能代替这些事实。画面上下边界、焦距和高度仅在影响动作与证据可辨认时补充。

先写完整主体动作链与环境变化，再补必要表情、特效和服饰细节。微观描述淹没动作时，删去不影响剧情的细节，保留承接动作与结果。

### 表情与肢体

在情绪转折处选择可见反应：眉弓或眉间、眼睑、瞳孔与视线、嘴部、下颌。按当前景别取用，写出触发动作与停顿；情绪目标和声音段可直接表达情绪方向。

大幅转头考虑肩躯干联动，抬手交代肩臂路径，下蹲或起身交代重心与支撑。保持接触点、握持、前后遮挡与受力反应连续，人物动作不套用固定角度阈值。

### 位置与视线

镜头1建立出场主体的位置、朝向、视线与姿态，后续用动作解释变化，收束时交代空间落点。看向或触及目标前，给出目光或手部路径。

区分事实已经存在、角色有机会感知、实际注意并反应、观众获得信息。关键物件、接触或表情真正清楚可辨后才计入观众的有效阅读窗口，不能把移入、遮挡或失焦时间都算进去。阅读可以与动作、对白并行；结合画幅、主体大小和同时的信息负担安排，不机械追加停顿。依赖视觉监控的操作先看清触点，再完成接触或检查，避免目光与手部任务相互矛盾。

画面段写摄影、动作、表情与环境变化，设计理由和心理推断留在设计章。角色名称、参考资产和说话人使用同一身份。

### 转场、收束与跨镜首尾帧传递（Frame Chaining）

首镜状态与故事板第一格（`Shot #1`）、末镜状态与第九格（`Shot #9`）使用同一份设计核对。跨段连接成对记录在 transitions.incoming/outgoing 中；需要生成的转场写入实际镜头并留出时间。出入段的具体方法见[分镜衔接设计](../../sd-storyboard/references/storyboard-rules.md#分镜衔接设计)。

目标模型支持首尾帧时，可用已验收的成片帧或经**模板6C（T6C）**生成的匹配目标风格全分辨率单帧执行**跨镜首尾帧传递（Frame Chaining）**。T6/T6B切图使用`--grid-kind storyboard`；T5的`spatial`切片只表示空间朝向，不自动具备起末时序。T6B线稿默认作结构参考，写实或彩色首尾帧应先用T6C制作对应风格的全分辨率单帧：
- **同机位连续动作**：核对前镜成片末态与后镜计划起态后，可用该末帧作后镜首帧；图像必须保留后镜需要的人物、物件与空间。上一镜最后一帧若是黑场、遮挡、失焦或错误状态，先修订/选帧。文件传递有助于维持边界，但不保证动作、光影或音色连续，仍需返片。
- **换机位/切景别**：使用本镜已核对起末态及实际构图的单帧；其他真实节点仅按模型能力作姿态或结构参考，不把额外审阅特写当成原物理镜头的一部分。

### 目标模型与纯视觉兼容输出

按具体模型记录参考能力，字段见[数据契约](../../references/project-data.md)，导出分支见[本地工具](../../references/tools.md)。纯视觉`wan`块是文本转换草稿，不承接声音参考；使用前核对残留音频指令、动作、文字和可见嘴部，不能仅凭输出名称判断模型能力。

短镜头的动作密度按[整场预算](../../references/scene-timing.md)复核，阶段数量提示不能替代实际时长与返片验证。

需要切换观看位置时，在正文写出切出时具体动作阶段、目光转移、物件变化或声源节点；持续观察则写实际结束取景。切镜只改变观看位置，画外的移动、接触和声音按经过时间继续，不能停住等画面返回。跨片段衔接在各自正文交代真实起止状态，不用另一段的编号或同上代替；同一原台词只执行一次。

### 形变、对抗与介质特效

形变先按[9B 形变专项](../../sd-storyboard/references/design-9b.md#9b-4b-形变专项)选定连续变化或遮挡、切镜、后期方案，再把各阶段的可见变化、接触和环境反应写入镜头。

对抗节拍应能看见进攻、应对、计划被打断、结果与代价。回合数量服从剧情，重击可留短暂停顿和环境反应，节奏不只靠持续加快镜头表现。

水、火、烟、气等介质应写明流动、厚薄、破散和接触，不因招式名称带“剑”就默认为金属。发光、自发光与实体化依设定选择。

## 风格、参考资产与跨镜一致性

- 主体层写当前可见的固有造型与配色，风格层写叙事光影与整体调色。角色身份沿用全局设定，服饰、伤损、湿身按当前有效状态覆写；不可见五官不必为词语齐全而重述。QC特征词扫描只作复核提示，不能代替可见性和身份审查。
- **多人同框空间分区**：开头明确各角色的画面方位与既定造型，有实际图时分别绑定`@素材N`，无图时使用文字。尾约束按本镜可见关系选择，不强制改服装颜色制造反差，也不把背景群像逐一扩成主要角色资产。
- **局部特写与背影镜头的五官降噪**：当整个分镜均为纯手部、足部微距特写或纯背影时，动态正文（尤其是万相 Wan 纯视觉版）只重点描述可见的手部骨节、肤质、袖口与道具接触，不写入正脸五官与眼神词，防止视频模型强行拉远景别或让人物诡异扭头露脸。
- **物理光位与同场色温**：主光绑定场景固定方位后再推导当前受光面；连续时间、光源未变时保持基调。点灯、停电、天气和特效引起的变化按源稿及设计记录并延续；冷暖WARN提示复核，不禁止有依据的变化。
- **场景交互状态持久化**：状态变化持续记录，可见、即将交互或影响因果的部分写入本镜正文；不可见痕迹无需全量塞入尾约束。仅在机位、状态和目标模型输入适合时复用前镜末帧，不把所有换机位或反打强制接成同构首帧。

### 四类高频特殊场景的一致性稳定策略

| 场景类型 | 常见崩坏现象 | 提示词与机位稳定策略 |
|---|---|---|
| **1. 狭小封闭空间**<br>（车内、电梯、轿厢、密室） | 墙体/车顶缺失、空间变宽 | 从可成立的固定或小幅机位试起，明确车窗框、门框等现有边界。确需大运动时先验证空间路径，不把某个焦距或固定镜头当作唯一方案 |
| **2. 线性连续移动空间**<br>（长廊追逐、楼梯上下、街巷同行） | 墙纹流动、台阶或门窗数量变化 | 使用原场景已有的柱、门窗或路标建立相对位置；实际等距时才写等距。运镜随剧情选择，不能为追求稳定擅增重复建筑或改变场所尺度 |
| **3. 室外动态天气场景**<br>（雨夜、风雪、浓雾、强风） | 雨雪或人物湿身状态跨镜丢失 | 分别核对空中介质、地面反馈与人物受候状态；只写当前可见部分，源稿触发的天气变化有明确时间与后续状态 |
| **4. 纵深大场景群戏**<br>（宴会厅、朝堂、宗门广场、闹市） | 背景群演失真、动作抢戏 | 区分剧情所需群体行为与背景活动，按观看重点选择景别、焦点或分镜；允许弱化无叙事作用的背景，不能把必要的围观、骚动或协同行动全部改成虚化剪影 |

## 声音脚本

环境音与 BGM 在镜头块前各写一行；动作音效、台词、OS 和 NAR 放在所属镜头。

| 类型 | 写法 |
|---|---|
| 环境音 | 声源、动作和声音质感，说明持续或中断 |
| BGM | 乐器、节奏、情绪与进入、收束，为对白留白 |
| 动作音效 | 紧跟触发动作，区分碰撞、摩擦、破裂等声源与材质 |
| 角色台词 | 声线、表达、语速、语气后接引号中的原文 |
| OS 内心独白 | 标记 OS，保留角色核心音色，设计为非嘴部发声 |
| NAR 旁白 | 标记 NAR，使用与角色可区分的叙述者声线 |

角色声线沿用`characters.voice`，实际音频按[声音参考资产](../../references/voice-reference-assets.md)绑定角色与模型副本。参考提供声音身份，本镜重新设计情绪、语速和停顿；样片转写不进入正式台词。台词与动作、停顿和表情形成节拍，不为每句话追加整套动作。

原始台词保留字词、说话角色和顺序，允许标点与空白调整；引号只包正式台词、OS或NAR，不包设计说明。

### 语速、情绪与标点

语速使用急促、快速、匀速、平缓、缓慢、凝滞等自然语言，试读与返片核对时长、停顿和表演。

| 情绪方向 | 语速起点 | 表达示例 | 标点用途 |
|---|---|---|---|
| 愤怒或兴奋 | 急促 | 气息短促、重音清楚 | ！强调，——中断 |
| 悲伤或疲惫 | 缓慢 | 气息不足、尾音渐弱 | ……迟疑或留白 |
| 恐惧或紧张 | 快速 | 换气频繁、短句断续 | ，断句，？疑问 |
| 果决或陈述 | 匀速 | 咬字清楚、句尾收束 | 。结束完整语义 |
| 温柔或释怀 | 平缓 | 气息绵长、尾音柔和 | ，自然衔接，。收束 |
| 犹疑或低语 | 凝滞 | 轻声、语句间留白 | ……停顿，？悬问 |

这些是表演起点，按人物与情境调整。台词优先使用中文逗号、双引号、六点省略号“……”和中文破折号“——”，再按项目文本约定检查。

字幕、UI 与画内文字按[制作交接](../../references/production-workflow.md)确定实现方式；默认动态提示词无字幕，后期清单另行交付。

## 交付与返片

按[分镜审阅清单](../../sd-storyboard/references/quality-gates.md)对照八岗位、segments、关键帧和动态正文。修改摄影、动作或证据时点后回算预算，再更新内容与依赖；元数据和设计理由留在代码块外，尾段按[约束写法](../../references/constraints.md)填写。

运行[QC](../../references/tools.md)后，返片核对摄影、表演、空间、时长和声画关系；声音身份、串读与跨镜变声按[声音听审要求](../../references/voice-reference-assets.md#返片听审与回改)检查。未生成的媒体保留未验证状态。
