# 动态设计与声音方法

动态提示词承接分镜的摄影、动作、空间、声音与特效设计。实际字段见[动态模板](templates.md)，跨模块格式见[规则权威表](../../references/rule-authority.md)，源稿与制作交接见[制作流程](../../references/production-workflow.md)，数据与 QC 见[项目数据契约](../../references/project-data.md)。

## 时长与剧情承载

一个 shot 对应一条动态 prompt，segments 和每镜配音表使用从零开始的局部时间轴；跨镜总时间由后续剪辑累加。每个物理镜头使用一个镜头块，可包含连续动作或多句对话。

按剧情、动作、换景、完整台词、停顿与反应分配时间，一个区间只定义一次。超出承载量时拆分分镜；需要删改台词时回到源稿和交接修订，再更新下游。

结合铺垫、危机、反转和悬念选择节奏。动作高潮可用短促动作与停顿交替，文戏保留可读反应，过渡镜也按叙事需要安排。

## 镜头、动作与空间

### 运镜与信息优先级

每块明确景别、运动方式、机位、构图、透视或前遮挡、景深和焦点。根据需要使用固定、推拉、摇移、跟拍、升降、环绕或手持；一个主要运动服务一个叙事目的，转折有可见动机。

先写完整主体动作链与环境变化，再补必要表情、特效和服饰细节。微观描述淹没动作时，删去不影响剧情的细节，保留承接动作与结果。

### 表情与肢体

在情绪转折处选择可见反应：眉弓或眉间、眼睑、瞳孔与视线、嘴部、下颌。按当前景别取用，写出触发动作与停顿；情绪目标和声音段可直接表达情绪方向。

大幅转头考虑肩躯干联动，抬手交代肩臂路径，下蹲或起身交代重心与支撑。保持接触点、握持、前后遮挡与受力反应连续，人物动作不套用固定角度阈值。

### 位置与视线

镜头1建立出场主体的位置、朝向、视线与姿态，后续用动作解释变化，收束时交代空间落点。看向或触及目标前，给出目光或手部路径。

画面段写摄影、动作、表情与环境变化，设计理由和心理推断留在设计章。角色名称、参考资产和说话人使用同一身份。

### 转场与收束

首镜状态与故事板第一格、末镜状态与第九格使用同一份设计核对。跨段连接成对记录在 transitions.incoming/outgoing 中；需要生成的转场写入实际镜头并留出时间。出入段的具体方法见[分镜衔接设计](../../sd-storyboard/references/storyboard-rules.md#分镜衔接设计)。

### 形变、对抗与介质特效

形变先按[9B 形变专项](../../sd-storyboard/references/design-9b.md#9b-4b-形变专项)选定连续变化或遮挡、切镜、后期方案，再把各阶段的可见变化、接触和环境反应写入镜头。

对抗节拍应能看见进攻、应对、计划被打断、结果与代价。回合数量服从剧情，重击可留短暂停顿和环境反应，节奏不只靠持续加快镜头表现。

水、火、烟、气等介质应写明流动、厚薄、破散和接触，不因招式名称带“剑”就默认为金属。发光、自发光与实体化依设定选择。

## 风格与参考资产

- 主体层写角色、道具的固有造型与配色，包括发色、瞳色、服装分区和材质本色；风格层写叙事光影、整体调色与渲染质感，避免重复。
- 风格层以项目整体风格开头，按主光、辅光、轮廓光、环境光说明来源、方向、色温或冷暖、强弱关系与效果。数值光比转为可见的明暗关系。
- 角色与道具参考可保留固有配色；动态场景和故事板参考的光影、色彩与画面风格按 R-REF-001 隔离。T8 以图为主，T9 保留完整视觉文字。
- 配色、材质和光影用语符合项目风格；平涂或卡通按其表现方法取用，画质措辞仅表达视觉目标。

## 声音脚本

环境音与 BGM 在镜头块前各写一行；动作音效、台词、OS 和 NAR 放在所属镜头。

| 类型 | 写法 |
|---|---|
| 环境音 | 声源、动作和声音质感，说明持续或中断 |
| BGM | 乐器、节奏、情绪与进入、收束，为对白留白 |
| 动作音效 | 紧跟触发动作，区分碰撞、摩擦、破裂等声源与材质 |
| 角色台词 | 声线、表达、语速、语气后接引号中的原文 |
| OS 内心独白 | 标记 OS，保留角色核心音色，设计为非嘴部发声 |
| NAR 旁白 | 标记 NAR，使用与角色可区分的叙述者声线 |

角色声线沿用 characters.voice，单句表演和 OS 改变表达方式，保持声音身份。台词与动作、停顿、表情形成节拍，不为每句话追加整套动作。

原始台词保留文字、说话角色和顺序，允许标点与空白调整。镜头中的真实台词可以包含“模板”“首帧”等普通词；引号只用于实际台词、OS 或 NAR，不能将前置说明或尾约束加引号冒充配音。

### 语速、情绪与标点

语速使用急促、快速、匀速、平缓、缓慢、凝滞等自然语言。朗读与试听核对台词时长、停顿和表演，混音与编码参数留给实际音频工具。

| 情绪方向 | 语速起点 | 表达示例 | 标点用途 |
|---|---|---|---|
| 愤怒或兴奋 | 急促 | 气息短促、重音清楚 | ！强调，——中断 |
| 悲伤或疲惫 | 缓慢 | 气息不足、尾音渐弱 | ……迟疑或留白 |
| 恐惧或紧张 | 快速 | 换气频繁、短句断续 | ，断句，？疑问 |
| 果决或陈述 | 匀速 | 咬字清楚、句尾收束 | 。结束完整语义 |
| 温柔或释怀 | 平缓 | 气息绵长、尾音柔和 | ，自然衔接，。收束 |
| 犹疑或低语 | 凝滞 | 轻声、语句间留白 | ……停顿，？悬问 |

这些是表演起点，按人物与情境调整。台词优先使用中文逗号、双引号、六点省略号“……”和中文破折号“——”，再按项目文本约定检查。

字幕、UI 与画内文字按[制作交接](../../references/production-workflow.md)确定实现方式；默认动态提示词无字幕，后期清单另行交付。

## 交付与返片

按 R-VISUAL-001 清理未填占位、编辑注释、机制标签和跨模板省略指令，正文描述当前画面。元数据、设计理由与检查结果放在代码块外，尾约束按[约束写法](../../references/constraints.md)填写。

运行[项目数据契约](../../references/project-data.md)中的检查后，返片核对摄影效果、表演、空间连续性、配音时长、口型与声音衔接。
