# 动态设计与声音方法

承接八岗位分镜设计编写动态视频提示词与声音脚本。字段顺序见[templates.md](templates.md)，公共规则见[rule-authority.md](../../references/rule-authority.md)。

## 1. 运镜、动作与视线过程

- **运镜过程**：明确拍摄主体、相对人物与场景锚点的机位朝向、起幅画面、运动启动节点、路径节奏与落幅画面（固定镜头同样写明起幅、画内变化与落幅）。
- **动作与肢体联动**：写出准备、移动路径、接触点、握持关系、前后遮挡与受力结果；情绪转折通过眉间、眼睑、视线、唇部与下颌等可见微表情呈现，不使用抽象情绪词代替可见动作，也不对人物动作使用数值角度（如“转头45度”）。
- **视线与证据阅读**：手部精细操作前先交代视线落向接触点；证据有效阅读窗口从物体在取景、光照和焦点下真正清楚可辨时起算。

## 2. 跨镜首尾帧传递与一致性

- **跨镜首尾帧传递（Frame Chaining）**：
  - 同机位连续承接的分镜，在核对上一镜成片末态清晰、无黑场或失焦后，可将其末帧作为下一镜首帧输入。
  - 换机位或切景别的分镜，使用`T6C`生成的匹配目标风格全分辨率起末单帧作为首尾帧边界。
- **跨镜外观与声线锁死**：
  - 露脸镜头完整保留角色不可变面部骨相DNA，换装/战损/湿身状态按当前有效服饰覆写；纯手部、足部或纯背影镜头移除不可见正脸五官与张嘴词（导出器生成的`wan`纯视觉块也会自动剥离不露脸镜头的五官子句）。
  - 多人同框在主体层逐角色内联绑定`@素材N`与画面方位。
  - 未绑定`VOICE-`音频文件时，所有发声镜头必须沿用`characters[].voice`中的核心声线词（如“清亮女中音”）。
  - 同一场景（`scene_ids`相同）相邻分镜保持光影冷暖基调一致；无故冷暖突变会触发QC `WARN`。

### 四类高频特殊场景稳定策略

| 场景类型 | 常见问题 | 提示词与机位策略 |
|---|---|---|
| 1. 狭小封闭空间（车内、电梯、密室） | 墙体/顶棚缺失、空间变宽 | 采用固定或小幅机位，明确车窗框、门框等近处围合边界 |
| 2. 线性连续移动（长廊、楼梯、街巷） | 墙纹流动、台阶门窗数量跳变 | 以场景既有柱体、门窗或定锚物建立相对位置参照 |
| 3. 室外动态天气（雨夜、风雪、浓雾） | 雨雪或人物湿身状态跨镜丢失 | 同时写明空中介质、地面反馈与人物湿发/衣摆贴肤状态并跨镜承接 |
| 4. 纵深大场景群戏（宴会厅、广场） | 背景群演失真抢戏 | 区分前景核心动作与背景群体层次，用景深控制视觉焦点 |

## 3. 声音脚本规范

环境音与BGM在`镜头1`之前各占一行；动作音效、角色台词、OS与NAR写在所属`镜头N`内。

| 声部 | 写法规范 |
|---|---|
| 环境音 | `环境音：全片持续铺设[声源、动作与质感]。` |
| BGM | `BGM：[乐器、节奏、情绪与收束方式，为对白留出空间]。` |
| 动作音效 | 紧随触发动作描述碰撞、摩擦或接触声源与材质 |
| 角色台词 / OS / NAR | 自然语言声线、语速与语气引导词后接双引号原文（OS/NAR在声线前标明类型） |

### 标准语速与标点对照

台词引号内禁用顿号（`、`）、波浪号（`～`）、方引号（`「」`/`『』`）、英文省略号（`...`）及叠字标点（`！！`/`？？`）；破折号使用`——`，省略号使用六点`……`。

| 情绪方向 | 标准语速词 | 表达与标点建议 |
|---|---|---|
| 愤怒 / 兴奋 | `急促` | 气息短促、重音清楚；用`！`强调，`——`表示打断 |
| 恐惧 / 紧张 | `快速` | 换气略频、短句断续；用`，`断句，`？`追问 |
| 果决 / 陈述 | `匀速` | 咬字清楚、句尾收束；用`。`收尾 |
| 温柔 / 释怀 | `平缓` | 气息绵长、尾音柔和；用`，`与`。`自然衔接 |
| 悲伤 / 疲惫 | `缓慢` | 气息微弱、尾音渐轻；用`……`表现迟疑或留白 |
| 犹疑 / 低语 | `凝滞` | 压低声音、字间停顿；用`……`与`？`表现悬问 |
