# 动态视频提示词与声音脚本

将分镜设计转为视频提示词、角色声线、台词和音效/BGM文本；需要音色参考时，承接角色声音身份母版与实际模型副本。输入为采用的源稿、八岗位设计、资产清单、声音需求及实际参考素材。

## 模式选择

| 参考条件 | 模板 | 文字职责 |
|---|---|---|
| 无参考图 | T7 | 完整描述角色、场景、道具与动作 |
| 以图为主要视觉依据 | T8 | 声明继承范围，补动作、情绪、光影和声音 |
| 图文共同约束 | T9 | 参考声明加全量描述；完整分镜默认使用 |

先遵从用户指定的模板；明确要求T9但没有图片时，删除不存在的参考声明，保留全量文字，不虚构素材位。

声音参考独立于视觉模式；按[声音参考资产](../references/voice-reference-assets.md)核对文件、目标模型和角色归属，没有音频时不分配声音槽。

一个shot对应一条动态prompt，segments对应片段内部的物理镜头。按动作与空间承载量设计镜头，不按台词条数拆镜。

## 执行与交付

- 按[整场预算](../references/scene-timing.md)确定时长，再用[动态模板](references/templates.md)组装独立text代码块。正文写主体、相对机位、起幅、摄影过程、落幅、证据可读时点及切点。
- 台词沿用源稿文字与顺序，允许标点及空白调整；需要改词时回到编剧环节。
- 环境音和BGM置于镜头块前，动作音效、对白、OS和NAR放进所属镜头。
- 默认生成无字幕；画内文字与后期叠字按[制作交接](../references/production-workflow.md#制作交接表)分别记录。
- 计划发声起止写入`segments.lines.start/end`；声音参考文件长度不替代对白预算，样片文字不进入正式台词。
- 完整项目执行[QC和导出](../references/tools.md)。模型输出分支与文件检查以该工具说明为准；纯视觉兼容块不用于声音参考投喂。

动作、摄影、声音及返片方法见[动态设计](references/dynamic-rules.md)，格式见[公共规则](../references/rule-authority.md)和[尾约束写法](../references/constraints.md)。
