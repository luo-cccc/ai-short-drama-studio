# 分镜设计与制作规划

将源剧本转为资产、节拍、镜头与声音设计，并组织静动态提示词。输入为本批采用的剧本版本、人物/场景/道具设定、画幅和目标时长；未定稿的材料按其草稿状态使用。

## 制作步骤

1. 按[制作交接](../references/production-workflow.md#制作交接表)核对源稿范围，整理资产、动作与信息节拍、原始台词及源定位映射。
2. 根据动作、空间和声音承载量拆分制作片段，规划全局资产与逐镜引用。单集时长与片段时长分开。
3. 按[八岗位方法](references/design-9b.md)完成叙事、摄影、光影、动作、空间、台词、声音和特效决策。
4. 按[分镜方法](references/storyboard-rules.md)检查轴线、关键帧、转场和声音衔接，再按[审阅清单](references/quality-gates.md)修订。
5. 调用静态与动态模板，补齐project.json。修改完成后捕获依赖快照，运行QC并导出。

需要改剧情或台词时回到源剧本修订，随后更新交接和受影响数据。命令、完整JSON要求与审查状态的程序行为见[项目数据与工具](../references/project-data.md)。

## 模板分工

| 对象 | 模板 |
|---|---|
| 全局角色、道具、场景 | [静态T1、T2、T3](../sd-static-assets/references/templates.md)，扩图用T4 |
| 多视角空间参考 | 静态T5 |
| 彩色提案／线稿视频参考 | 静态T6／T6B |
| 文生／图生／混合参考视频 | [动态T7／T8／T9](../sd-dynamic-video/references/templates.md)，完整分镜默认T9 |

画幅与参考继承按[公共规则](../references/rule-authority.md)，模板正文由各模块维护。

## 导出交付

- project.md：项目设定、节拍摘要、按执行顺序排列的原台词、全局静态提示词和总分镜表。
- 每个shot.id对应一份分镜Markdown，固定五章：设计思维、静态提示词、动态提示词、配音音效、素材位与资产清单。

设计章按八岗位展示knowledge与decision，提示词各自独立代码块。详细底稿可另留，不与导出文档重复维护。

### 总分镜表字段

导出器固定15列：镜号、合规时长档位、分镜核心功能、核心剧情梗概、分镜头数量、切镜节奏、核心镜头语言设计、核心光影基调、关键音频节点、转场设计、核心配音台词内容、参考图资产、9B设计编号、9B-1B审查状态、备注。
