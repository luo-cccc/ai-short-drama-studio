# 分镜设计与制作规划

将源剧本转为资产、节拍、镜头与声音设计，并组织静动态提示词。输入为本批采用的剧本版本、人物/场景/道具设定、画幅和目标时长；未定稿的材料按其草稿状态使用。

## 制作步骤

1. 按[制作交接](../references/production-workflow.md#制作交接表)核对源稿范围，整理资产、动作与信息节拍、原始台词及源定位映射。视频需要音色参考时，按[声音参考资产](../references/voice-reference-assets.md)登记角色声音卡、试听与实际音频状态。
2. 先按[整场预算](../references/scene-timing.md)排对白、操作、反应、证据阅读和转场的顺序与并行，再拆制作片段并规划资产与引用。单集、场次与片段时长分开。
3. 按[八岗位方法](references/design-9b.md)完成叙事、摄影、光影、动作、空间、台词、声音和特效决策。
4. 按[分镜方法](references/storyboard-rules.md)检查轴线、关键帧、转场和声音衔接，再按[审阅清单](references/quality-gates.md)修订。
5. 完整项目调用静态与动态模板，补齐project.json，修改完成后捕获依赖快照、运行QC并导出。局部任务按约定交付预算、设计或提示词，不为送检强建完整JSON。

剧情或台词回改先更新源稿，再同步受影响的制作数据。

## 模板分工

| 对象 | 模板 |
|---|---|
| 全局角色、道具、场景 | [静态T1、T2、T3](../sd-static-assets/references/templates.md)，扩图用T4 |
| 多视角空间参考 | 静态T5（同画幅满幅3×3无字九视角，可经 `slice_grid.py` 切分对位绑定） |
| 彩色／黑白线稿 3×3 关键帧故事板及单帧首尾帧重绘 | 静态T6／T6B／T6C，按已定摄影与行动采样；静止保持不为凑格新增动作或机位，T6C用于生成全分辨率目标风格首尾帧 |
| 文生／图生／混合参考视频 | [动态T7／T8／T9](../sd-dynamic-video/references/templates.md)，完整分镜默认T9 |
| 角色声音身份参考 | [声音参考资产](../references/voice-reference-assets.md)，独立于T7/T8/T9的视觉模式，按模型能力绑定音频 |

## 导出交付

- `project.md`：项目设定、节拍摘要、按执行顺序排列的原台词、全局静态提示词、已登记声音参考资产和15列总分镜表。
- 每个`shot.id`对应一份五章文档：设计思维、静态提示词、动态提示词、配音音效、素材位与资产清单。

设计章展示八岗位的`knowledge`与`decision`。声音参考状态放第四章，实际音频槽放第五章；模型输出分支、覆盖保护和命令见[本地工具](../references/tools.md)，画幅与继承见[公共规则](../references/rule-authority.md)。

### 总分镜表字段

导出器固定15列：镜号、合规时长档位、分镜核心功能、核心剧情梗概、分镜头数量、切镜节奏、核心镜头语言设计、核心光影基调、关键音频节点、转场设计、核心配音台词内容、参考素材资产、9B设计编号、9B-1B审查状态、备注。
