# 9B 八岗位设计

本文件提供逐镜专业设计方法。它由 Agent 或人工使用，不是八个实际运行的服务，也不是 Python 自动审查器。公共格式与范围见 [规则权威表](../../references/rule-authority.md)。

设计顺序为 9B-1A 设定叙事目标，9B-2 至 9B-8 协同形成方案，9B-1B 审阅。数据中用 shots.design 的八个 role 分别记录 knowledge 和 decision；详细底稿按需要保留，导出器只呈现八岗摘要。

## 9B-1A 总导演·叙事（director）

**判断依据**：段落功能、因果关系、人物目标、情感弧线和信息密度。

**需要决定**：
- 本镜交代、推进、转折或收束什么？
- 观众进入和离开时分别知道什么，情绪如何变化？
- 本镜与前后镜有什么呼应，哪些事件和原台词必须保留？
- 摄影、光影、动作、空间与声音共同服务什么目标？

将核心功能写入 shots.function，其余理由凝练进 director 的决策。不用“高级感”“有张力”等概括替代具体选择。

## 9B-2 摄影导演（camera）

**判断依据**：景别功能、观看方向、构图重心、透视、景深、焦点、运动与叙事关系。

**需要决定**：
- 物理镜头数、各镜起止时间和切换动机。
- 每镜机位、景别、观看效果、运动路径和焦点变化。
- 与角色运动、关键台词和动作高潮的配合。
- 入场承接、出场衔接和是否需要后期工具。

时间写入 segments，衔接写入 transitions；具体参数和选择理由可写在决策与提示词中。当前 Schema 没有独立的十二列运镜表，不声称脚本逐字段核查了摄影方案。

### 轴线操作

1. 说明世界空间中是哪两个主体的连线、它在画面上的方向，以及机位所处侧别。
2. 先保持同侧观看关系；位置描述用场景中的门、墙、台阶等参照。
3. 越轴需要动机。可用骑轴、中性镜头、主体带轴或插入特写帮助重新建立方位。
4. 同时检查 T6 各格与动态镜头，不能让角色左右关系无解释地翻转。

## 9B-3 光影导演（lighting）

**判断依据**：光源动机、硬软光、明暗关系、色温、色彩与人物可读性。

**需要决定**：
- 在项目统一风格下，主光、辅光、轮廓光与环境光分别从哪里来、产生什么效果。
- 辅光怎样保留或压低暗部，如何引导视觉焦点。
- 同场跨镜的光源方向与色调如何保持，何时有剧情驱动的变化。
- 特效是否照亮角色或环境，是否与摄影意图冲突。

四光位是本项目的描述组织方式，不表示现场必须有四盏灯。摄影参数范围按 R-PARAM-001；T3／T5 基础空间光与叙事光分工按 R-LIGHT-001。

## 9B-4 动作指导（action）

**判断依据**：重心、支撑、惯性、关节范围、接触、动作节奏和意图。

**需要决定**：
- 从起点到终点的移动路径、准备、接触、受力和收势。
- 重要事件之后的视线、身体反应与选择，不跳过动作因果。
- 与道具的握持和遮挡，交叉肢体、快速动作等易失真位置。
- 复杂动作是否应减速、拆镜或减少同刻事件，以便观看和实际生成测试。

不要在同一时刻给角色相互矛盾的进攻、防御或移动意图；设计目标是否成立仍需审片。

### 9B-4B 形变专项

变身、觉醒、化形、年龄变化或物种转换时，先选连续可见的形变，还是以遮挡、切镜或后期完成变化。选择依据是叙事目的、实际模型测试和制作成本，不假定某一模型已能稳定完成。

- 把变化拆成可见部位与阶段，写明颜色、轮廓、纹理或体量如何改变。
- 为每阶段保留可读时间，不固定套用层数或帧数。
- 肢体、衣料和体表的变化应同步，避免相互穿插或硬换。
- 光效如用于强化变化，说明是否遮挡；确需遮挡时，把它写成有意的制作手法。
- 与特效岗位确认变化触发、作用范围及环境反应。

## 9B-5 空间调度（staging）

**判断依据**：站位传达的关系、纵深、走位、道具位置和机位配合。

**需要决定**：
- 所有出场角色的位置、朝向、视线和彼此关系。
- 入口、出口、遮挡与定锚物；移动和接触的完整路径。
- 开头、过程中和结尾的空间状态，与前后镜是否衔接。
- 哪些主体在画外，何时进入可见范围。

建筑空间关系先建立，单镜头再映射为画面方向。T5 多视角用建筑相对方位，避免把同一物体在不同机位中的“画面左侧”当成固定位置。

## 9B-6 台词编辑（dialogue）

**判断依据**：原始台词、潜文本、节奏、沉默和台词与动作的配合。

**需要决定**：
- 本镜逐句认领哪些台词，其说话者、所属节拍和顺序是否正确。
- 表演提示如何配合角色当下目标；哪些反应可以由动作承担。
- 是否存在原稿没有的台词、错位的 OS 或用角色介绍替代台词的问题。
- 台词是否能在计划区间内自然完成；需要改词时回到剧本源头修订。

以已确认的剧本与 dialogues 为执行来源，不把未采用的小说原文直接视作最终台词。程序对账范围见数据契约；人物潜文本与自然度由审阅者判断。

## 9B-7 音频师（sound）

**判断依据**：同步、对位、延伸等声画关系，声音层次与注意力分配。

**需要决定**：
- 环境音如何建立空间，哪些声源在近处、远处或画外。
- 动作音效何时触发、材质如何区分、哪些声音是剧情线索。
- BGM 的乐器、节奏、进入退出和前后镜桥接。
- 配音是否留有空间，声音是否掩盖关键台词。

把可交付描述写入 audio.ambience、audio.music、audio.effects。当前结构不保存逐音轨工程时间轴或混音曲线，精确同步与响度需外部工具制作和试听。

## 9B-8 特效师（vfx）

**判断依据**：特效是实体环境变化、视觉叠加还是后期处理；其触发、形态、遮挡、层次和光照影响。

**需要决定**：
- 特效为何出现、由什么动作触发、在何处发展和结束。
- 可见形态、颜色、运动方向、与角色和环境的接触。
- 与动作、摄影、光影和声音是否协调。
- 是否需要独立参考素材或外部合成。

无特效需求时仍保留 vfx 岗位条目，写明本镜不需要特效；不添加无用的特效资产。

## 9B-1B 总导演·审阅

在专业使用时，审阅完成后再把镜头标为可投产；需要修改时明确指出岗位、问题和修订方向。

- 叙事目标与各岗决策是否一致，有没有互相矛盾的动作、镜头或光源？
- 台词、事件、关键情绪节点是否承接已确认内容？
- 相邻镜的角色、道具、时间、空间、光影与声音是否连续？
- 特效、动作与音效是否同步，信息是否过密？
- 设计是否能转为具体的提示词与实际制作操作？
- 摄影与光影方案是否协调，实际返回画面是否需要返修？

设计编号和状态记录在 review：unreviewed、needs_revision、approved。该状态是输入记录，Python 只做结构检查与显示；当前导出器允许输出未审查草稿，不自动作出专业批准，也不证明已经获得用户确认。
