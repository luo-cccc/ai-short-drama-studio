# 分镜设计方法

本文件用于把剧本转为镜头、关键帧和声音方案。制作顺序与源稿交接见[制作流程](../../references/production-workflow.md)，跨模块约定见[规则权威表](../../references/rule-authority.md)，数据与 QC 见[项目数据契约](../../references/project-data.md)。

## 分镜、镜头与剧情

一个分镜是一个制作片段，对应一条动态提示词，片段内可以有多个物理镜头。按动作、台词、信息揭示和停顿规划时长；超出 R-SPACE-001 的承载范围时增拆片段，不为预设镜数删剧情，也不按台词条数机械切镜。

逐项认领原剧本事件、动作、台词和情绪转折。beat_ids 关联剧情节拍，segments.lines 关联原台词；设计时还要核对具体内容是否落地，不能只完成 ID 关联。

同场戏可拆成多段，单段也可跨空间。换空间时交代移动或转场，保留场景引用与定锚物；跨段后重新建立站位。开头给出正在发生的动作、位置与视线，结尾交代动作落点和新获得的信息。

## 分镜衔接设计

先确定上一镜离开时和下一镜进入时的画面、情绪与声音，再选连接手法。

| 方法 | 常见用途 |
|---|---|
| 动作匹配 | 从同一动作的相邻阶段切入 |
| 视线匹配 | 从观看者转到被看对象 |
| 声音先入 | 下一段声音先到，连接对话或揭示 |
| 运镜动势延续 | 保持运动方向和节奏 |
| 尾帧与首帧对应 | 保持位置、姿态与构图中心，改变景别时给出动机 |
| 光影渐隐渐显 | 情绪沉淀或段落转换 |
| 焦点虚化 | 调整注意或进入新主观状态 |
| 主体出画入画 | 用运动带动换场 |
| 硬切 | 保持紧张或形成明确对照 |
| 闪白或黑屏 | 时空变化或有意断章 |
| 特写支点 | 用道具或局部连接不同画面 |

连续动作优先保持动作与视线，关键揭示可用声音先入或特写支点；情绪留白由前后段落共同决定。

在 transitions.outgoing 与下一镜 transitions.incoming 中成对记录离开状态、进入状态、连接方式及必要的时间。首镜说明开场，末镜说明落幅。

### 画面内转场

需要在生成画面中完成转场时，将出段和入段分别写进相邻提示词，并在时间规划中留出空间。

| 方式 | 上镜出段 | 下镜入段 |
|---|---|---|
| 渐暗或渐白 | 逐渐暗至黑或亮至白 | 从同色场逐渐显出画面 |
| 闪白或骤黑 | 短促强光或黑场覆盖 | 从同色场快速恢复 |
| 焦点变化 | 主体逐渐失焦 | 从虚化中重新聚焦 |
| 摇甩 | 急速甩动形成方向性模糊 | 同方向模糊减速稳定 |
| 光源遮盖 | 光效扩散充满画面 | 光效收敛露出新内容 |
| 遮挡 | 主体或物件遮满画面 | 对应遮挡移开 |
| 出入画 | 主体走出画框 | 按衔接关系从对应方向入画 |

转场时长服从动作与叙事；对白桥接、环境声延续和 BGM 也要衔接。叠化、划像或音频剪辑需要后期时，在设计中注明实际制作方式。

## 关键帧与空间

按审阅后的镜头计划提取静态关键帧。T6/T6B 第一格与动态开头、第九格与动态结尾对照角色位置、姿态、表情、道具和环境状态。九格是动作节点，不等于九个物理镜头；每格标明所属物理镜头。

T5 保持场景结构；其中某个视角用于开头参考时，采用对应的相机位置、朝向与静态镜头参数。静态图描述凝固瞬间，运动路径放在调度图或动态镜头中。

静动态提示词以同一份剧本、执行数据与设计为依据。出现差异时修正实际内容，不用“与另一模板一致”代替描述。图板字段与版式见[静态模板](../../sd-static-assets/references/templates.md)。

### 轴线与越轴

存在对话、对视或对抗关系时，先确定两个主体的连线、其在画面中的方向，以及机位所在的建筑或空间侧别。连续镜头保持已建立的方位。

需要越轴时，可用骑轴、中性镜头、主体带轴或插入特写重新建立关系，并说明关系翻转、换场或失衡的叙事动机。同时核对故事板各格与动态镜头的左右关系。

## 镜头与系列规划

景别、机位、构图、透视、景深和焦点服务本镜信息。摄影参数按 R-PARAM-001 选择，并配合可见的观看效果，不单独堆砌数值。

多集项目同时核对时间线、固定设定与待回收线索；系列连续性保存在共享设计记录中。

## 参考与声音规划

为故事板各角色分别绑定可识别的参考资产，避免多角色身份混在一张未注明的图里。参考来自既有设定；彩色 T6、线稿 T6B 和动态参考的继承范围按 R-REF-001 区分，素材位还需与实际上传图片核对。

声音设计先确定固定声线、单句表演、声源位置和跨镜衔接。角色声线沿用 characters.voice；单句情绪改变表达方式，保留角色身份。原始 dialogues 决定台词文字、角色、顺序和所属节拍。

环境音建立空间，动作音效对应触发动作与材质，BGM 配合进入、退出和对白留白。独立配音输入应包含声线、表演方向和完整台词；停顿与时长通过朗读和试听确认。具体写法见[动态声音方法](../../sd-dynamic-video/references/dynamic-rules.md#声音脚本)。
