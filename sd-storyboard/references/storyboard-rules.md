# 分镜设计方法

本文用于 Agent 和人工设计。格式、时间、画幅、参考继承与尾约束以 [规则权威表](../../references/rule-authority.md) 为准；模板字段不在这里另设一套定义。文中编号用于其他模块引用，不代表脚本已实现同名检查。

## 分镜、镜头与剧情

**规则1／22 · 时长与镜头关系**：一个分镜是一个制作片段，对应一条动态提示词，片段内可以有多个物理镜头。片段时长按 R-SPACE-001、R-TIME-001 规划，具体时长由动作、台词、信息揭示和停顿决定，不由固定字数推导。

**规则1A · 空间边界**：同场戏可拆成多段，单段也可跨空间。换空间时交代移动或转场，保留场景引用与定锚物；跨段后重新确认站位，不能直接跳到未建立的位置。

**规则1B · 剧情继承**：逐项认领原剧本事件、动作、台词和情绪转折，剧情量过大时增拆片段。数据中以 beat_ids 关联节拍，以 segments.lines 关联原台词。脚本能判断这些关系是否覆盖、台词是否保留，不能判断一个摘要是否已完整表达原文细节。

## 规则1C · 分镜衔接设计

先确定上一镜离开时和下一镜进入时的画面、情绪与声音，再选连接手法。下列是可选方法，不是按题材自动执行的规则引擎。

| ID | 方法 | 常见用途 |
|---|---|---|
| A1 | 动作匹配 | 从同一动作的相邻阶段切入 |
| A2 | 视线匹配 | 从观看者转到被看对象 |
| A3 | 声音先入 | 下一段声音先到，连接对话或揭示 |
| A4 | 运镜动势延续 | 保持运动方向和节奏 |
| A5 | 尾帧—首帧对应 | 保持位置、姿态与构图中心，改变景别时给出动机 |
| B1 | 光影渐隐渐显 | 情绪沉淀或段落转换 |
| B2 | 焦点虚化 | 调整注意或进入新主观状态 |
| B3 | 主体出画入画 | 用运动带动换场 |
| C1 | 硬切 | 保持紧张或形成明确对照 |
| C2 | 闪白／黑屏 | 时空变化或有意断章 |
| C3 | 特写支点 | 用道具或局部连接不同画面 |

连续动作优先保持动作与视线，关键揭示可用声音先入或特写支点；情绪是否需要留白，由前后段落共同决定，不机械禁止某种剪辑手法。

在 transitions.outgoing 与下一镜 transitions.incoming 中成对描述：离开状态、进入状态、连接方式及必要的时间。首镜说明开场，末镜说明落幅，不虚构不存在的前后镜。

### E1–E7 转场效果

需要生成画面内转场时，把同组“出段＋入段”写进相邻提示词，并在时间规划中留出空间：

| ID | 出段 | 入段 |
|---|---|---|
| E1 | 逐渐暗至黑／亮至白 | 从同色场逐渐显出画面 |
| E2 | 短促闪白／骤黑 | 从同色场快速恢复 |
| E3 | 焦点逐渐失去 | 从虚化中重新聚焦 |
| E4 | 急速甩动形成方向性模糊 | 同方向模糊减速稳定 |
| E5 | 光效扩散充满画面 | 光效收敛露出新内容 |
| E6 | 主体或物件遮满画面 | 同类遮挡移开 |
| E7 | 主体走出画框 | 主体在对应方向入画 |

真实叠化、划像或音频剪辑可能需要后期工具完成，本仓库不执行这些操作。不要用“转场已完成”替代制作计划。

## 关键帧与空间

**规则8／8A · 首尾与关键帧对应**：按已审阅的镜头计划提取静态关键帧。T6 第一格与动态开头、最后一格与动态结尾对照角色位置、姿态、表情、道具状态和可见环境。T5 空间图保持场景结构；其起始视角如用于开头参考，应复制对应机位与静态镜头参数。静态图写凝固瞬间，动态提示词写动作过程，不能把推、拉、摇、移直接当作静态画面的运动。

两者都以已确认的剧本、结构化执行数据和设计方案为依据。发现 T6 与 T9 不一致时修正实际内容，不在提示词中写“与另一模板一致”代替描述。

**规则8B · 分模式参考**：按 R-REF-001 区分 T5、彩色 T6、线稿 T6B 与动态 T8/T9。特别注意线稿只取造型结构，不继承色彩、光影或渲染风格。

**规则8C · 轴线与越轴**：存在对话、对视或对抗关系时，先写清主体连线、其在画面的方向、机位处在哪个建筑或空间侧别。连续镜头保持已建立的方位；需要越轴时可用骑轴、中性镜头、主体带轴或插入特写过渡，并说明关系翻转、换场或失衡的叙事动机。T6 各格也检查左右关系，不能只检查动态文字。

**规则9 · 故事板**：按静态 T6／T6B 实际模板组织图板；右栏九格是动作节点的静态选取，不等于必须有九个物理镜头。外画幅与格内画幅分别处理，版式标注与剧情画面分开。

**规则10 · 交付结构**：分镜文件的五章由 [模块入口](../SKILL.md) 定义，导出器按项目数据生成。设计底稿可以比交付更详细，正式文件只展示八岗知识与决策摘要，不附无关流程痕迹。

**规则11／12／14／18 · 镜头设计**：景别、机位、构图、透视、景深与焦点应服务本镜信息。焦距和光圈等参数按实际工具需要采用，参数边界引用 R-PARAM-001。把观看效果写进自然语言，避免分离的参数堆砌。不要声称仓库会自动选择最佳镜头或保证输出效果。

**规则13 · 叙事收束**：开头建立正在发生的动作、位置与视线，结尾交代动作落点和新获得的信息。首尾状态用画面内容表达，不给动态投产文字加机制标签。

**规则15／16／23／25 · 提示词边界**：自包含、参数范围与字数建议按规则权威表和模板执行。生成参数不等于文件编码规格；仓库不控制外部模型的帧率、码率和实际分辨率。

**规则20／27 · 总表与系列**：总表字段以入口为准；多集项目在设计时同时核对时间线、固定设定与待回收线索。当前 Schema 没有专门的全季管理或音频生成任务模型，不把设计记录冒充这些功能。

## 配音与声音（VOICE）

| ID | 设计要求 |
|---|---|
| VOICE-01 | 以声源、音色、节奏和变化描述声音；混音与编码参数留给实际音频工具 |
| VOICE-02 | 交给外部工具的单条输入应自包含，不依赖“同上”等省略 |
| VOICE-03 | 角色声线以 characters.voice 为基准；仓库没有“官方认证”词库 |
| VOICE-04 | 分清固定音色和单句表演变化，不因情绪改变角色身份 |
| VOICE-05 | 用标点与自然语言协同表达停顿、轻重和语速，精确时长通过试听确认 |
| VOICE-06 | 需要生成独立配音时，将声线、表演方向和台词正文整合到工具输入 |
| VOICE-07 | 以原始 dialogues 为台词来源，保留文字、角色、顺序和所属节拍；标点与空白的对账规则见数据契约 |
| VOICE-08 | 核对声线提示、标点、动作与情绪是否协调，不把标点解释为精确音高编码 |
| VOICE-09 | 环境音写空间与声源，动作音效写触发动作与材质，BGM 写乐器、节奏和变化 |

导出器目前输出角色声线表、人声台词表、环境音／BGM／音效表；不自动把它们合成独立音频提示包，也不计算真实配音时长。实际媒体需要外部工具生成与试听。

## 角色参考（SB）

- **SB-01**：故事板各角色的参考应可独立识别，在素材位清单中绑定对应资产 ID，避免把多角色身份混在一张未注明的图里。
- **SB-02**：角色参考来自已确认设定；彩色与线稿的继承范围按实际模板处理，文字描述用视觉比例。参考 ID 只表示逻辑关联，不证明图片已经生成或审核。

## 输出边界

设计理由与检查报告放在提示词代码块外。投产块只保留实际内容，交付文档不附冗长的检查清单；QC 运行时仍应报告真实错误和警告。需要用户处理的问题应清楚说明，不用“后台静默”隐藏未解决的问题。
