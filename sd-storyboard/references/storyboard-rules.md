# 分镜设计方法

将源剧本转化为制作片段（`SHOT`）、物理镜头（`segments`）、关键帧故事板与声音方案。

## 1. 片段划分与证据可读

- 每个`SHOT`对应一条5–30秒的动态提示词，内部可包含1个或多个物理镜头（`segments`）。先按[整场时间预算](../../references/scene-timing.md)排定动作、对白、反应与证据阅读窗口，再按承载量切分片段。
- 区分**客观事实存在**、**角色感知与反应**、**观众看清证据**三个时点：证据有效阅读窗口从物体在取景、光照、遮挡和焦点下真正清楚可辨时起算，可与稳定的动作或对白共用时间。

## 2. 镜头衔接与画面内转场

切点须落在具体动作阶段、目光转移、物件状态或声音节点；切往他处期间，画外动作与持续声源按实际经过时间继续，回切承接最新相位，跨镜对白不重复起句。跨片段首尾状态成对写入相邻分镜的`transitions.outgoing`与`transitions.incoming`。

| 衔接手法 | 适用场景 |
|---|---|
| 动作匹配 | 同一动作的相邻阶段跨镜接续 |
| 视线匹配 | 从观察者切向其注视的目标物或人物 |
| 声音先入（J-Cut / L-Cut） | 下一镜或上一镜的对白/音效跨切点桥接 |
| 运镜动势延续 | 相邻镜头保持一致的推拉或横移运动方向与节奏 |
| 特写支点 / 遮挡转场 | 利用核心道具特写或前景物体遮挡完成时空切换 |
| 渐暗/渐白/闪白/虚焦 | 时空跨越、闪回或主观状态切换（需在镜头正文中留出过渡时间） |

## 3. 故事板采样与空间轴线

### 九格关键帧采样（T6 / T6B）
- `T6`/`T6B`采用与`project.aspect_ratio`同构的满幅3×3九宫格，`Shot #1`对应`0.0`秒起态，`Shot #9`对应切出末态，每格标明时间节点与所属`物理镜头N`。
- 九格是在既定`segments`上的静态采样，不等于九次切镜；节点不足时从已有动作或静止保持中采样，不为凑满九格凭空增加特写或新机位。

### 轴线、正反打与防穿帮
- **180度轴线与正反打背景**：先确定人物关系轴线与相机在建筑空间中的物理位置和朝向，绑定朝向匹配的`T5`空间切片（`--grid-kind spatial`），推导当前视角真实可见的前中背景，不在反打镜头中照搬正打背景。
- **多人同框分区**：明确各角色在画面左/中/右或前/后景的方位，并逐角色内联绑定各自的`@图片N`/`@素材N`。
- **场景状态与光位连续**：开门、取物、破损或点火等状态变化在后续镜头持续保留；同一时段与光源条件下，主光固定在建筑相对方位，按当前机位推导受光面。

## 4. 摄影过程表达

每个物理镜头须写出完整可执行过程：**拍摄主体与观看重点 → 相对人物与空间锚点的机位、高度、朝向、焦距光圈与起幅画面 → 运动启动节点、路径节奏与焦点转移（或固定镜头的画内关系变化） → 落幅画面与稳定状态**。避免仅写“轻推”“跟拍”“有张力”等笼统词。
