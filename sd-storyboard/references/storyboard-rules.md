# 分镜设计方法

本文件用于把剧本转为镜头、关键帧和声音方案。顺序与源稿交接见[制作流程](../../references/production-workflow.md)，格式见[公共规则](../../references/rule-authority.md)，数据见[契约](../../references/project-data.md)，命令见[本地工具](../../references/tools.md)。

## 分镜、镜头与剧情

一个分镜是一个制作片段，对应一条动态提示词，片段内可以有多个物理镜头。先按[整场预算](../../references/scene-timing.md)核对本场事件、动作、完整台词、反应与证据可读时间，再按实际承载和动作、话轮、揭示边界拆分片段。超出 R-SPACE-001 的承载范围时增拆片段，不为预设镜数删剧情，也不按台词条数机械切镜。

逐项认领原剧本事件、动作、台词和情绪转折。beat_ids 关联剧情节拍，segments.lines 关联原台词；设计时还要核对具体内容是否落地，不能只完成 ID 关联。

同场戏可拆成多段，单段也可跨空间。换空间时交代移动或转场，保留场景引用与定锚物；跨段后明确承接的站位，不能把重新交代当作人物复位。开头给出正在发生的动作、位置与视线，结尾交代动作落点与本段承担的信息、关系或情绪变化。

### 观看重点与证据可读

每个物理镜头先明确具体人物、物件或关系，以及观众此刻需要辨认的动作、状态或变化。分别核对事实是否存在、角色是否有机会感知、实际注意或误解了什么，以及观众何时获得信息。观众看见画外危险不等于角色已经知道；角色说“看见了”也不能替代观众需要辨认的证据。按采用的剧本安排揭示，不为增加信息量新增线索或改变人物知情。

证据可读窗口从对象在实际取景、光照、遮挡与清晰范围下真正可辨认时起算，移入画面、被挡住或失焦的时间不一概计入。按画幅、主体大小及同刻对白、操作、读字的负担判断；可以在对白或动作持续时让证据保持清楚，共用同一时间，不机械另加停顿。承载不足时先调整构图、同框关系或焦点安排，再回到整场预算调整时长与拆分。确认空间、观察表演、静默和余韵也可有作用，不要求每镜新增事实。

## 分镜衔接设计

先确定上一镜离开时和下一镜进入时的画面、情绪与声音，再选连接手法。

切点落在具体动作阶段、目光变化、物件状态或声音节点，说明此时观众已能辨认什么、后镜接着看什么；不只写“情绪收紧时切镜”。切去听者、物件或另一空间时，仍在画外进行的动作、环境变化与声源按实际经过时间继续，回切承接当前相位，不自动暂停、完成或重新起手。对白跨镜保持同一话轮与声源，不因换画面重说。

| 方法 | 常见用途 |
|---|---|
| 动作匹配 | 从同一动作的相邻阶段切入 |
| 视线匹配 | 从观看者转到被看对象 |
| 声音先入 | 下一段声音先到，连接对话或揭示 |
| 运镜动势延续 | 保持运动方向和节奏 |
| 尾帧与首帧对应 | 保持位置、姿态与构图中心，改变景别时给出动机 |
| 光影渐隐渐显 | 情绪沉淀或段落转换 |
| 焦点虚化 | 调整注意或进入新主观状态 |
| 主体出画入画 | 用运动带动换场 |
| 硬切 | 保持紧张或形成明确对照 |
| 闪白或黑屏 | 时空变化或有意断章 |
| 特写支点 | 用道具或局部连接不同画面 |

连续动作优先保持动作与视线，关键揭示可用声音先入或特写支点；情绪留白由前后段落共同决定。

跨制作片段在本段 transitions.outgoing 与下一段 transitions.incoming 中成对记录离开状态、进入状态、连接方式及必要的时间。段内切镜及持续动作写入对应 segments.description 和实际镜头正文。首镜说明开场，末镜说明落幅。

### 画面内转场

需要在生成画面中完成转场时，将出段和入段分别写进相邻提示词，并在时间规划中留出空间。

| 方式 | 上镜出段 | 下镜入段 |
|---|---|---|
| 渐暗或渐白 | 逐渐暗至黑或亮至白 | 从同色场逐渐显出画面 |
| 闪白或骤黑 | 短促强光或黑场覆盖 | 从同色场快速恢复 |
| 焦点变化 | 主体逐渐失焦 | 从虚化中重新聚焦 |
| 摇甩 | 急速甩动形成方向性模糊 | 同方向模糊减速稳定 |
| 光源遮盖 | 光效扩散充满画面 | 光效收敛露出新内容 |
| 遮挡 | 主体或物件遮满画面 | 对应遮挡移开 |
| 出入画 | 主体走出画框 | 按衔接关系从对应方向入画 |

转场时长服从动作与叙事；对白桥接、环境声延续和 BGM 也要衔接。叠化、划像或音频剪辑需要后期时，在设计中注明实际制作方式。

## 关键帧与空间

按审阅后的镜头计划提取静态关键帧。T6/T6B采用与项目主画幅同构的满幅3×3九宫格，第1/9格与动态起末态对照角色位置、姿态、表情、道具和环境。九格不是九次切镜；每格注明实际时点和所属物理镜头，遵循该时刻的机位、景别、焦点与遮挡。节点不足时从已发生的观察、接触、显露和结果中采样，静止观察或余韵允许相同状态保持；不新增剧情或特写以凑格。审阅放大图另行交付，确需改变摄影时先同步执行设计和预算。

T5保持纯净无字场景结构；按每格真实机位和朝向选空间切片，使用`--grid-kind spatial`，格号不代表起末时序。T6/T6B切图使用`--grid-kind storyboard`；线稿作为结构参考，目标写实或彩色首尾帧须另行核对并制作匹配风格的单帧。静态图描述凝固瞬间，相机与角色运动路径记录在八岗位设计和动态正文中，不在图面绘制调度图或轨迹。

静动态提示词以同一份剧本、执行数据与设计为依据。按同一物理镜头和时间窗，对照八岗位`decision`、`segments.description`、T6/T6B采样节点与动态正文：主体、机位、摄影、切点、动作、台词及证据窗口保持一致。段描述保留执行事实，故事板呈现定格，动态正文写完整过程；不能用“与另一模板一致”或重捕快照代替内容修订。图板字段见[静态模板](../../sd-static-assets/references/templates.md)。

### 轴线、越轴与正反打场景防穿帮

存在对话、对视或对抗关系时，先确定两个主体的连线、其在画面中的方向，以及机位所在的建筑或空间侧别。连续镜头保持已建立的方位。

- **正反打背景**：依相机位置、朝向和场景拓扑重算可见前中背景，绑定真实朝向匹配的T5切片。正反打可共享实际仍可见的建筑或远景；不可机械照抄，也不因“反打”标签强删可见物或凭空增建反向背景。
- **双人/多人同框分区**：按画面左/中/右或前/后景明确角色、参考图和既定造型。已有图时分别绑定；无图时用完整文字，不虚构素材。辨识可以依服饰结构、发型、体型和位置，不为制造反差擅改同制服或既定配色。
- **场景交互状态**：开门、取物、破坏或点火后，在衔接记录中持续维护新状态；当前取景能看见、角色将交互或因果依赖的变化写入相应正文。不可见旧痕迹无需在每镜尾约束中全量重述，但不能无依据地恢复初始状态。
- **建筑锚定光位**：同一时段、光源条件未变时，将主光锚定在场景固定方位，再推导当前机位下的受光面。太阳移动、点灯、停电或特效等有依据的变化须登记触发与后续状态；色温扫描只提示复核，不能以同一scene_id禁止有动机的光照变化。

需要越轴时，可用骑轴、中性镜头、主体带轴或插入特写重新建立关系，并说明关系翻转、换场或失衡的叙事动机。同时核对故事板各格与动态镜头的左右关系。

## 镜头与系列规划

景别、机位、构图、透视、景深和焦点服务本镜信息。摄影参数按 R-PARAM-001 选择，并配合可见的观看效果，不单独堆砌数值。

每个物理镜头将摄影写成连贯过程：明确主要拍摄人物或唯一物件及观看重点，摄影机相对人物与空间锚点的位置、高度、朝向，起幅包含哪些对象；有运动时写启动节点、实际路径、相对主体的变化、运动节奏与范围，关注或焦点转移时写从谁到谁及触发；最后写落幅中主体位置、取景与仍在运动或稳定观察的状态。运动节奏用可见过程表达，不新增速度参数。只写“轻推”“跟拍”“有压迫感”不能代替这些执行事实。

固定镜头同样写明机位、起幅、画内动作与关系如何变化及结束画面，不要求为丰富技法而移动。推轨、摇摄、变焦和转焦按实际行为分别表达；可以协同发生，不将光学变化当成摄影机位移。具体过程落实在 camera 决策、段描述与动态正文中，选择理由仍留在设计章。

多集项目同时核对时间线、固定设定与待回收线索；系列连续性保存在共享设计记录中。

## 参考与声音规划

为故事板各角色分别绑定可识别的参考资产，避免多角色身份混在一张未注明的图里。参考来自既有设定；彩色 T6、线稿 T6B 和动态参考的继承范围按 R-REF-001 区分，素材位还需与实际上传图片核对。

声音设计先确定固定声线、单句表演、声源位置和跨镜衔接。角色声线沿用 characters.voice；单句情绪改变表达方式，保留角色身份。原始 dialogues 决定台词文字、角色、顺序和所属节拍。

环境音建立空间，动作音效对应触发与材质，BGM配合进入、退出和对白留白。角色音频按[声音资产规范](../../references/voice-reference-assets.md)准备，本镜表演与正式台词写入视频提示词；停顿与时长由试读和返片确认，具体写法见[动态声音方法](../../sd-dynamic-video/references/dynamic-rules.md#声音脚本)。
